以下「內層」都要加密後放進外層 `data`。`acc` **只送玩家帳號**，不要加 `kiwi01_`。

時間、IP、語系寫錯最常變成 `PARAM_INVALID`。

## POST `/player/add`

建立會員。已存在回 `ACC_EXIST`——可以當成功，接著去登入。

內層：

```json
{ "acc": "jordan", "name": "Amy" }
```

| 欄位 | 必填 | 規則 |
|---|---|---|
| `acc` | 是 | 英數，6–60，會被轉成小寫 |
| `name` | 是 | 最長 30 |

成功：

```json
{
  "code": "OK",
  "data": {
    "acc": "kiwi01_jordan",
    "player_acc": "jordan",
    "player_id": 123
  }
}
```

`data.acc` 是平台完整帳號，給你對帳用。之後請求仍送 `jordan`。

## POST `/player/balance`

**只有轉帳錢包**用這支查平台餘額。單錢包請實作你自己的 `/player/balance` 給我們查。

```json
{ "acc": "jordan" }
```

成功 `data`：`currency`（如 `TWD`）、`balance`（數字）。

## POST `/player/login`

回傳可打開的大廳或遊戲 URL。請用玩家的**真實 IP**，不要填伺服器 IP。

| 欄位 | 必填 | 規則 |
|---|---|---|
| `acc` | 是 | 英數 6–60 |
| `lang` | 是 | BCP 47，例如 `zh-TW`、`en`、`vi` |
| `ip` | 是 | IPv4 或 IPv6 |
| `device` | 是 | 只能是 `DESKTOP` 或 `MOBILE`（全大寫） |
| `game_code` | 否 | 有值進該遊戲；空或省略進大廳 |
| `return_url` | 否 | 必須是合法 URL |

```json
{
  "acc": "jordan",
  "lang": "zh-TW",
  "ip": "203.0.113.10",
  "device": "MOBILE",
  "game_code": "MLCQ"
}
```

成功：

```json
{ "code": "OK", "data": { "url": "https://....?token=...&lang=zh-TW" } }
```

把 `url` 開在玩家瀏覽器或 WebView。`token` 已含在 query，不要再改。

| code | 處理 |
|---|---|
| `ACC_NOT_FOUND` | 先 add |
| `ACC_NOT_ACTIVE` / `ACC_SUSPEND` | 不要進遊戲 |
| `GAME_NOT_FOUND` | `/game/list` 核對代碼（大小寫我們會正規化，但仍須是有效遊戲） |
| `GAME_MAINTAIN` | 提示維護 |

## POST `/player/logout`

```json
{ "acc": "jordan" }
```

省略 `acc`：登出該商戶底下**所有**會員。請勿在排程裡誤送空值。
