---
title: 玩家
description: 建立、餘額、登入、登出。
---

內層 `acc` 不含代理前綴。時間欄位為 Unix 秒。

## POST `/player/add`

建立會員。

| 欄位 | 必填 | 型別 | 約束 |
|---|---|---|---|
| `acc` | 是 | string | 英數，6–60，儲存為小寫 |
| `name` | 是 | string | 長度 ≤ 30 |

```json
{ "acc": "jordan", "name": "Amy" }
```

```json
{
  "code": "OK",
  "data": {
    "acc": "kiwi01_jordan",
    "player_acc": "jordan",
    "player_id": 123
  }
}
```

後續請求仍傳送 `jordan`。`ACC_EXIST` 表示帳號已存在，可視為建立完成。

## POST `/player/balance`

查詢平台餘額。適用於轉帳錢包。單錢包餘額由商戶接口提供。

| 欄位 | 必填 | 型別 | 約束 |
|---|---|---|---|
| `acc` | 是 | string | 英數，6–60 |

回應 `data`：`currency`、`balance`。

## POST `/player/login`

核發大廳或遊戲 URL。`ip` 為玩家位址。

| 欄位 | 必填 | 型別 | 約束 |
|---|---|---|---|
| `acc` | 是 | string | 英數，6–60 |
| `lang` | 是 | string | BCP 47，例如 `zh-TW` |
| `ip` | 是 | string | IPv4 或 IPv6 |
| `device` | 是 | string | `DESKTOP` \| `MOBILE` |
| `game_code` | 否 | string | 省略則進入大廳 |
| `return_url` | 否 | string | 合法 URL |

```json
{
  "acc": "jordan",
  "lang": "zh-TW",
  "ip": "203.0.113.10",
  "device": "MOBILE",
  "game_code": "MLCQ"
}
```

```json
{ "code": "OK", "data": { "url": "https://example/?token=...&lang=zh-TW" } }
```

用戶端開啟 `data.url`，不得修改 `token`。

| code | 條件 |
|---|---|
| `ACC_NOT_FOUND` | 玩家不存在 |
| `ACC_NOT_ACTIVE` | 玩家未啟用 |
| `ACC_SUSPEND` | 玩家已暫停 |
| `GAME_NOT_FOUND` | 遊戲代碼無效 |
| `GAME_MAINTAIN` | 維護中 |

## POST `/player/logout`

| 欄位 | 必填 | 說明 |
|---|---|---|
| `acc` | 否 | 省略時登出該商戶全部會員 |

```json
{ "acc": "jordan" }
```
