查詢接口不變更餘額。時間為 Unix 秒。`end_at` 須大於 `start_at`，否則 `PARAM_INVALID`。

下列接口速率為每商戶每分鐘 10 次，超出為 `TOO_MANY_REQUESTS`：`/bet_rec/list`、`/jp_rec/list`、`/bet_report/list`、`/scratch_card_rec/list`。

`acc` 不含前綴；省略表示該商戶全部玩家。

## POST `/game/list`

內層得為 `{}`。`data.list` 元素：

| 欄位 | 說明 |
|---|---|
| `code` | 遊戲代碼，對應登入 `game_code` |
| `name` | 名稱（多語系） |
| `game_category_code` | 類別 |
| `game_type_code` | 類型 |
| `id` | 內部識別 |

## POST `/bet_rec/list`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `page` | 是 | ≥ 1 |
| `perpage` | 是 | 1–1000 |
| `start_at` | 是 | Unix 秒 |
| `end_at` | 是 | 大於 `start_at` |
| `acc` | 否 | |

回應 `data`：`list`、`row_count`、`page_count`。

## POST `/bet_rec/detail`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `sn` | 是 | 長度 ≤ 120 |
| `lang` | 是 | BCP 47 |

## POST `/bet_rec/query`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `sns` | 是 | 1–100 個單號 |

`data.list` 元素含 `sn`、`status`。`UNKNOWN` 表示平台無此單，不得據此自動退款。

## POST `/bet_report/list`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `page` / `perpage` | 是 | perpage 1–1000 |
| `start_at` / `end_at` | 是 | |
| `report_unit` | 是 | `min` \| `day` |
| `time_unit` | 是 | `bet` \| `settle` |
| `acc` | 否 | |

## POST `/jp_rec/list`

參數同 `/bet_rec/list`。

## POST `/jp_rec/detail`

參數同 `/bet_rec/detail`。

## POST `/scratch_card_rec/list`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `page` / `perpage` | 是 | perpage 1–1000 |
| `start_at` / `end_at` | 是 | |
| `status` | 否 | `PENDING` \| `CLAIMED` \| `SCRATCHED` |
| `acc` | 否 | |
| `lang` | 否 | BCP 47 |
