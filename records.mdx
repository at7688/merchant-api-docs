查詢接口不變更餘額。`end_at` 須大於 `start_at`。成功信封見 [傳輸協議](/protocol)。`agent`／`member` 同 [轉帳](/transfer) 頁末。

時間欄位**不是**每支都用下注時間：

| 接口 | `start_at`／`end_at` 對應 |
|---|---|
| `/bet_rec/list` | `updated_at`（異動時間，含結算）。另以**下注日**（`beted_date`，UTC+8 當日 00:00）裁切，須落在「區間起日的前一天」到「區間結束日」之間。因此下注超過一天後才異動的單**查不到**，需改用 `/bet_rec/query` 依單號查 |
| `/jp_rec/list` | `created_at` |
| `/bet_report/list` | `beted_date` 或 `settled_date`／分鐘欄，值為 UTC+8（`Asia/Shanghai`）當日 00:00 之 Unix 秒 |
| `/scratch_card_rec/list` | `updated_at`（狀態變更時間） |
| `/transfer/list` | `created_at` |
| `/free_round/list` | `created_at` |

下列接口每商戶每分鐘 10 次：`/bet_rec/list`、`/jp_rec/list`、`/bet_report/list`、`/scratch_card_rec/list`。超出為 `TOO_MANY_REQUESTS`。

`acc` 不含前綴；省略或空字串表示不篩玩家。

</Card>

## POST `/bet_rec/list`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` | 是 | integer | ≥ 1 |

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總筆數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 注單列 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 注單單號 |
| `round_sn` | string | 局號 |
| `game_category_code` | string | [遊戲類別](/enums#game-category) |
| `game_type_code` | string | 類型 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 完整帳號 |
| `player_acc` | string | 不含前綴 |
| `bet_amount` | number | 投注額 |
| `win_amount` | number | 派彩額 |
| `valid_amount` | number | 有效投注。未結算（`PENDING`）與退款（`REFUND`）注單一律為 0 |
| `result` | number | 輸贏。已結算（`FINISH`）為派彩 − 投注；未結算與退款注單一律為 0（**不是** −投注額） |
| `free_game_type` | string | [免費遊戲](/enums#free-game-type) |
| `beted_at` | integer | 下注時間，Unix 秒 |
| `settled_at` | integer | 結算時間，Unix 秒；未結算可為 0 |
| `status` | string | [注單狀態](/enums#bet-status) |
| `agent` | object | 商戶摘要 |
| `member` | object | 玩家摘要 |
| `slot_bet_detail` | object | 遊戲端明細，結構依遊戲而異 |
</Card>

贈送旋轉產生之注單仍在本列表，`bet_amount` 為名目注額。本接口不另給「是否贈送」欄位。

## POST `/bet_rec/query`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `sns` | 是 | string[] | 1–100 個單號 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `list` | array | 與請求 `sns` 等長、順序相同 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 查詢之單號 |
| `code` | string | 每一列都有。有單為 `OK`，無單為 `BET_NOT_FOUND` |
| `status` | string | 僅當該列 `code` 為 `OK`：[注單狀態](/enums#bet-status)。無單時無此欄 |

先看該列 `code`，為 `OK` 才讀 `status`。外層 `code` 仍為 `OK`，表示本包請求成功。

```json
{
  "code": "OK",
  "data": {
    "list": [
      { "sn": "A", "code": "OK", "status": "PENDING" },
      { "sn": "B", "code": "OK", "status": "FINISH" },
      { "sn": "C", "code": "OK", "status": "REFUND" },
      { "sn": "D", "code": "BET_NOT_FOUND" }
    ]
  }
}
```

列上 `BET_NOT_FOUND` 不得據以自動退款。
</Card>

## POST `/bet_report/list`

<Warning>
**彙總資料只保留 60 天。** 查更早的區間會回 `code` 為 `OK`、`row_count` 為 0 的空清單，
不是錯誤——看起來像「那段期間沒有投注」。需要更早的資料請自行留存。
`/bet_rec/list` 的來源表不在清理範圍，不受此限。
</Warning>

`time_unit` 兩個軸的**統計母體不同**，不應互相加總或對帳：

| `time_unit` | 涵蓋的注單 |
|---|---|
| `bet` | 該期間所有落庫注單，**含未結算與已退款**（其 `win_amount`／`result` 為 0） |
| `settle` | **僅已結算（`FINISH`）** 注單 |

同一段期間 `bet` 軸的 `bet_count`／`bet_amount` 會大於 `settle` 軸，這是預期的。

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` | 是 | integer | ≥ 1 |
| `perpage` | 是 | integer | 1–1000 |
| `start_at` / `end_at` | 是 | integer | Unix 秒 |
| `report_unit` | 是 | string | [彙總週期](/enums#report-unit) |
| `time_unit` | 是 | string | [時間軸](/enums#time-unit) |
| `acc` | 否 | string | |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總列數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 彙總列 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `datetime` | string | 時間桶 |
| `bet_count` | integer | 注單數 |
| `bet_member_count` | integer | 下注人數 |
| `bet_amount` | number | 投注額 |
| `valid_amount` | number | 有效投注 |
| `win_amount` | number | 派彩額 |
| `result` | number | 平台輸贏 |
</Card>

## POST `/scratch_card_rec/list`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` / `perpage` | 是 | integer | perpage 1–1000 |
| `start_at` / `end_at` | 是 | integer | Unix 秒 |
| `status` | 否 | string | [刮刮卡狀態](/enums#scratch-status) |
| `acc` | 否 | string | |
| `lang` | 否 | string | [語系](/enums#lang)。省略時為 `zh-TW` |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總筆數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 票券列 |
| `summary` | object | 同篩選範圍之統計（不受 `status` 限制） |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | `SC_{id}` |
| `activity_name` | string | 活動名稱 |
| `card_code` | string | 卡面代碼 |
| `card_name` | string | 卡面名稱 |
| `prize_level` | string | 獎項等級 |
| `prize_amount` | number | 獎金 |
| `status` | string | [刮刮卡狀態](/enums#scratch-status) |
| `player_acc` | string | 不含前綴；未領取可為空 |
| `member` | object \| null | 玩家摘要；未領取為 null |
| `claimed_at` | integer | 領取時間，Unix 秒 |
| `scratched_at` | integer | 刮開時間，Unix 秒 |

`summary`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `total_count` | integer | 票數 |
| `pending_count` | string | 未領取（十進位數字字串） |
| `claimed_count` | string | 已領未刮（十進位數字字串） |
| `scratched_count` | string | 已刮（十進位數字字串） |
| `total_prize` | string | 獎金合計（十進位數字字串，**四位**小數） |
| `scratched_prize` | string | 已派獎金，對帳數（十進位數字字串，**四位**小數） |

<Warning>
除 `total_count` 外，其餘五個欄位是**字串**不是 number（例如 `"pending_count": "3"`、
`"total_prize": "150.5000"`，小數四位）。區間內一張票都沒有時，三個 `*_count` 會是**空字串** `""`。
請以字串解析後自行轉數值，不要用強型別直接映射成數字。
</Warning>
</Card>
