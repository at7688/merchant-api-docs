查詢接口不變更餘額。`end_at` 須大於 `start_at`。成功信封見 [傳輸協議](/protocol)。`agent`／`member` 同 [轉帳](/transfer) 頁末。

時間欄位**不是**每支都用下注時間：

| 接口 | `start_at`／`end_at` 對應 |
|---|---|
| `/bet_rec/list` | `updated_at`（異動時間，含結算）。僅用下注時間會漏掉「區間內才結算」的單 |
| `/jp_rec/list` | `created_at` |
| `/bet_report/list` | `beted_date` 或 `settled_date`／分鐘欄，值為 UTC+8 當日 00:00 之 Unix 秒 |
| `/scratch_card_rec/list` | `updated_at`（狀態變更時間） |
| `/transfer/list` | `created_at` |
| `/free_round/list` | `created_at` |

下列接口每商戶每分鐘 10 次：`/bet_rec/list`、`/jp_rec/list`、`/bet_report/list`、`/scratch_card_rec/list`。超出為 `TOO_MANY_REQUESTS`。

`acc` 不含前綴；省略或空字串表示不篩玩家。

## POST `/game/list`

<Card title="請求" icon="arrow-up-from-bracket">
內層得為 `{}`。僅回傳 `is_active=true` 之遊戲。維護中遊戲仍出現於清單，登入時才回 `GAME_MAINTAIN`。
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `list` | array | 遊戲清單 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | integer | 內部識別 |
| `code` | string | 遊戲代碼，對應登入 `game_code` |
| `name` | object | 多語系名稱，鍵為語系代碼 |
| `game_category_code` | string | 類別代碼 |
| `game_type_code` | string | 類型代碼 |
</Card>

## POST `/bet_rec/list`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` | 是 | integer | ≥ 1 |
| `perpage` | 是 | integer | 1–1000 |
| `start_at` | 是 | integer | 異動時間下界，Unix 秒（`updated_at`） |
| `end_at` | 是 | integer | 異動時間上界，須大於 `start_at` |
| `acc` | 否 | string | 篩選玩家 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總筆數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 注單列 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 注單單號 |
| `round_sn` | string | 局號 |
| `game_category_code` | string | 類別 |
| `game_type_code` | string | 類型 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 完整帳號 |
| `player_acc` | string | 不含前綴 |
| `bet_amount` | number | 投注額 |
| `win_amount` | number | 派彩額 |
| `valid_amount` | number | 有效投注 |
| `result` | number | 輸贏（派彩 − 投注） |
| `free_game_type` | string | `NONE`、`TRIGGER`、`PURCHASE` |
| `beted_at` | integer | 下注時間，Unix 秒 |
| `settled_at` | integer | 結算時間，Unix 秒；未結算可為 0 |
| `status` | string | `PENDING`、`PROCESSING`、`FINISH`、`CANCEL` |
| `agent` | object | 商戶摘要 |
| `member` | object | 玩家摘要 |
| `slot_bet_detail` | object | 遊戲端明細，結構依遊戲而異 |
</Card>

## POST `/bet_rec/detail`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `sn` | 是 | string | 注單單號，長度 ≤ 120 |
| `lang` | 是 | string | BCP 47 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `url` | string | 牌面結果頁 URL |

```json
{
  "code": "OK",
  "data": { "url": "https://lobby.example/gameResult?sn=SGP...&lang=zh-TW&is_jp=0" }
}
```
</Card>

## POST `/bet_rec/query`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `sns` | 是 | string[] | 1–100 個單號 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `list` | array | 與請求 `sns` 等長、順序相同 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 查詢之單號 |
| `status` | string | `PENDING`（含已收下、寫庫前）、`PROCESSING`、`FINISH`、`CANCEL`，或 `UNKNOWN`（查無） |

單號前 6 碼若為 `YYMMDD`（UTC+8 日期）則用於分區裁剪；否則仍可查詢。`UNKNOWN` 不得據以自動退款。
</Card>

## POST `/scratch_card_rec/list`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` / `perpage` | 是 | integer | perpage 1–1000 |
| `start_at` / `end_at` | 是 | integer | Unix 秒 |
| `status` | 否 | string | `PENDING`、`CLAIMED`、`SCRATCHED` |
| `acc` | 否 | string | |
| `lang` | 否 | string | BCP 47，影響名稱欄。省略時為 `zh-TW` |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總筆數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 票券列 |
| `summary` | object | 同篩選範圍之統計（不受 `status` 限制） |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | `SC_{id}` |
| `activity_name` | string | 活動名稱 |
| `card_code` | string | 卡面代碼 |
| `card_name` | string | 卡面名稱 |
| `prize_level` | string | 獎項等級 |
| `prize_amount` | number | 獎金 |
| `status` | string | `PENDING`、`CLAIMED`、`SCRATCHED` |
| `player_acc` | string | 不含前綴；未領取可為空 |
| `member` | object \| null | 玩家摘要；未領取為 null |
| `claimed_at` | integer | 領取時間，Unix 秒 |
| `scratched_at` | integer | 刮開時間，Unix 秒 |

`summary`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `total_count` | number | 票數 |
| `pending_count` | number | 未領取 |
| `claimed_count` | number | 已領未刮 |
| `scratched_count` | number | 已刮 |
| `total_prize` | number | 獎金合計 |
| `scratched_prize` | number | 已派獎金（對帳數） |
</Card>
