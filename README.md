# AT Gaming merchant API docs

Mintlify source for the public merchant API docs (transfer wallet + seamless wallet).

Repo: https://github.com/at7688/merchant-api-docs

## Connect Mintlify

1. Open https://app.mintlify.com/
2. Connect this GitHub repository and install the Mintlify GitHub App (this repo only).
3. Production branch: `main`.
4. After the first deploy, send the `*.mintlify.app` / `*.mintlify.site` URL so the full rewrite can start.

Do not paste Mintlify API keys into chat.

## Local preview

```bash
npm i -g mint
mint dev
```

Requires Node.js 20.17+.

## Languages

Default Traditional Chinese (`zh-Hant`), plus Simplified Chinese (`zh-CN`) and English (`en`).
