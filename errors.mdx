---
title: 錯誤碼表
description: 成功值僅為 OK。
---

`code` 等於 `OK` 表示成功。其餘值表示失敗。`data` 於多數錯誤為 `null`。

## 傳輸與鑑權

| code | 定義 | 處理 |
|---|---|---|
| `AGENT_NOT_FOUND` | 外層 `agent_acc` 無法對應代理 | 核對帳號 |
| `IP_NOT_ALLOWED` | 來源 IP 不在白名單 | 更新白名單 |
| `API_KEY_INVALID` | ApiKey 未設定或長度非 32 位元組 | 核對金鑰 |
| `DATA_FORMAT_INVALID` | `data` 非合法 hex | 核對編碼 |
| `DECRYPT_FAILED` | 解密失敗 | 核對金鑰、nonce 排列與明文 JSON |
| `PARAM_INVALID` | 內層未通過驗證 | 核對必填、型別、長度；時間為 Unix 秒 |
| `IP_BLOCKED` | 來源 IP 或國家被封鎖 | 變更來源或申請解除 |
| `ACC_NOT_ACTIVE` | 商戶未啟用 | 終止呼叫 |
| `ACC_SUSPEND` | 商戶已暫停 | 終止呼叫 |
| `TOO_MANY_REQUESTS` | 超過列表接口速率（每商戶每分鐘 10 次） | 降低頻率 |
| `INTERNAL_SERVER_ERROR` | 系統錯誤（伴隨 HTTP 500） | 結果未決，見下 |

上述錯誤在請求進入業務邏輯前發生。重試得使用原參數；轉帳不得因此更換 `sn`。

## 業務

| code | 定義 | 處理 |
|---|---|---|
| `ACC_EXIST` | 玩家帳號已存在 | 視為已建立 |
| `ACC_NOT_FOUND` | 玩家不存在 | 先呼叫 `/player/add`；確認未附加前綴 |
| `ACC_NOT_ACTIVE` | 玩家未啟用 | 拒絕進入遊戲 |
| `ACC_SUSPEND` | 玩家已暫停 | 拒絕進入遊戲 |
| `BALANCE_INSUFFICIENT` | 餘額不足 | 轉帳：入金後再出金。單錢包 bet：以此 code 回應平台 |
| `TRANSFER_SN_EXIST` | `sn` 已成功入帳 | 呼叫 `/transfer/check`。非失敗 |
| `TRANSFER_NOT_FOUND` | 無此轉帳 | 若前次為 HTTP 500，間隔後再查詢；仍無則可使用新 `sn` |
| `GAME_NOT_FOUND` | 遊戲代碼無效 | 以 `/game/list` 核對 |
| `BET_NOT_FOUND` | `/bet_rec/query` 查無此單 | 列上 `code`，外層仍 `OK`。不得自動退款 |
| `GAME_MAINTAIN` | 遊戲或類別維護中 | 延後進入 |
| `BET_AMOUNT_RANGE` | 注額超出該玩家該遊戲上下限 | 調整金額 |
| `FREE_ROUND_CAP` | 超過商戶當月贈送名目總額 | 不得重送同一批 |
| `WRONG_OPERATION` | 參數無法發放贈送旋轉 | 核對 `sn`、次數、注額 |

## 結果未決

HTTP 500 或連線中斷時，不得假設成功或失敗。

| 場景 | 規定 |
|---|---|
| `/transfer/add` | 以原 `sn` 呼叫 `/transfer/check`。查得紀錄即已入帳；`TRANSFER_NOT_FOUND` 後方可使用新 `sn` |
| 單錢包 | 以商戶帳本中該 `sn` 為準。`/bet_rec/query` 列上 `BET_NOT_FOUND` 時不得自動退款 |

單錢包回調成功時 `code` 為 `OK`。
