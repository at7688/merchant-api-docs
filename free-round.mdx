---
title: 贈送旋轉
description: 發放、取消、查詢。
---

讓指定玩家在指定遊戲免費轉 N 次。這些轉**不扣玩家餘額**、不累積 JP。

單錢包：玩家用贈送旋轉贏分時，我們仍可能打你的 `/player/win`（只有派彩，沒有對應的 bet 扣款）。請照 `sn` 加錢，不要因為沒看到 bet 就拒絕。

`bet_amount` 是名目注額，必須 **> 0**，且落在該玩家該遊戲的單注上下限，否則 `BET_AMOUNT_RANGE`。

## POST `/free_round/add`

`sn` 是你的活動單號，**重送同一 sn 不會再送一次**（冪等）。第二次成功時 `existed` 為 `true`。

```json
{
  "sn": "FR-20260917-001",
  "acc": "jordan",
  "game_code": "MLCQ",
  "bet_amount": 10,
  "count": 5,
  "expire_at": 1759300000
}
```

| 欄位 | 必填 | 規則 |
|---|---|---|
| `sn` | 是 | 最長 80 |
| `acc` | 是 | 不要前綴 |
| `game_code` | 是 | 須為有效遊戲 |
| `bet_amount` | 是 | > 0 |
| `count` | 是 | 1–100 |
| `expire_at` | 是 | Unix 秒；`0` 表示用系統預設有效期 |

成功：`{ "sn": "FR-20260917-001", "existed": false }`。

| code | 處理 |
|---|---|
| `FREE_ROUND_CAP` | 當月名目總額（次數 × 注額）超過商戶上限。不要重試同一批 |
| `BET_AMOUNT_RANGE` | 改注額 |
| `ACC_NOT_FOUND` | 先建帳 |
| `GAME_NOT_FOUND` | 核對 game_code |

遊戲端畫面（剩幾轉、鎖定注額）需遊戲配合，見對接窗口。平台會在玩家旋轉時自動消耗次數。

## POST `/free_round/cancel`

```json
{ "sn": "FR-20260917-001" }
```

剩餘次數歸零。找不到該活動：`ACC_NOT_FOUND`。已用掉的轉不會從歷史注單刪除。

## POST `/free_round/list`

| 欄位 | 必填 | 規則 |
|---|---|---|
| `page` | 是 | ≥ 1 |
| `perpage` | 是 | 1–100 |
| `acc` | 否 | |
| `start_at` / `end_at` | 否 | Unix 秒 |

`list` 每筆：`sn`、`game_code`、`bet_amount`、`total`（發放次數）、`remain`（剩餘）、`expire_at`、`created_at`。
