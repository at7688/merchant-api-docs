---
title: 贈送旋轉
description: 發放、取消、查詢。
---

向指定玩家發放指定遊戲之免費旋轉。該等旋轉不扣除玩家餘額、不計入 JP。

單錢包結算時，平台仍可能對商戶發出 `/player/win`（僅派彩、無對應 bet）。商戶須依 `sn` 加款。

`bet_amount` 為名目注額，須大於 0，且位於該玩家該遊戲單注上下限內，否則 `BET_AMOUNT_RANGE`。

## POST `/free_round/add`

`sn` 為冪等鍵。重複提交回傳 `existed: true`，不重複發放。

```json
{
  "sn": "FR-20260917-001",
  "acc": "jordan",
  "game_code": "MLCQ",
  "bet_amount": 10,
  "count": 5,
  "expire_at": 1759300000
}
```

| 欄位 | 必填 | 約束 |
|---|---|---|
| `sn` | 是 | 長度 ≤ 80 |
| `acc` | 是 | 不含前綴 |
| `game_code` | 是 | 有效遊戲代碼 |
| `bet_amount` | 是 | > 0 |
| `count` | 是 | 1–100 |
| `expire_at` | 是 | Unix 秒；`0` 表示系統預設有效期 |

```json
{ "code": "OK", "data": { "sn": "FR-20260917-001", "existed": false } }
```

| code | 定義 |
|---|---|
| `FREE_ROUND_CAP` | 當月名目總額（次數 × 注額）超過上限 |
| `BET_AMOUNT_RANGE` | 注額超出上下限 |
| `ACC_NOT_FOUND` | 玩家不存在 |
| `GAME_NOT_FOUND` | 遊戲代碼無效 |

剩餘次數由平台於旋轉時扣減。

## POST `/free_round/cancel`

```json
{ "sn": "FR-20260917-001" }
```

剩餘次數歸零。已消耗次數仍保留於注單歷史。無此活動時 `ACC_NOT_FOUND`。

## POST `/free_round/list`

| 欄位 | 必填 | 約束 |
|---|---|---|
| `page` | 是 | ≥ 1 |
| `perpage` | 是 | 1–100 |
| `acc` | 否 | |
| `start_at` / `end_at` | 否 | Unix 秒 |

`list` 元素：`sn`、`game_code`、`bet_amount`、`total`、`remain`、`expire_at`、`created_at`。
