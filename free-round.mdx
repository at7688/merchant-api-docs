---
title: 贈送旋轉
description: 發放、取消、查詢。
---

向指定玩家發放免費旋轉。不扣除玩家餘額、不計入 JP。單錢包結算時仍可能發出 win 回調。成功信封見 [傳輸協議](/protocol)。

| 項目 | 規定 |
|---|---|
| `sn` | 全站唯一。他商戶已使用則 `existed=true` 且不改本筆 |
| `game_code` | 轉大寫。空字串表示不限遊戲（消耗時任一遊戲皆可扣次數） |
| `expire_at` | `0` 或未指定＝自此刻起 30 日。超過 30 日之時間戳會被截成 30 日 |
| 月額度 | 名目合計 `bet_amount × count`，日曆月以 **UTC+8** 月初起算。後台未設上限則不檢查 |
| 注額 | 若指定遊戲，須落在該玩家該遊戲 `bet_min`／`bet_max` |

消耗順序：同一玩家多筆未用完紀錄依發放先後（`id` 升序）。

## POST `/free_round/add`

`sn` 為冪等鍵。重複提交不重複發放。

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `sn` | 是 | string | 活動單號，長度 ≤ 80 |
| `acc` | 是 | string | 玩家帳號，不含前綴 |
| `game_code` | 否 | string | 遊戲代碼，轉大寫。空＝不限遊戲 |
| `bet_amount` | 是 | number | 名目注額，> 0 |
| `count` | 是 | integer | 次數，1–100 |
| `expire_at` | 是 | integer | 到期 Unix 秒；`0` 表示系統預設 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 活動單號 |
| `existed` | boolean | `true` 表示此 `sn` 先前已發放，本次未再增加次數 |

```json
{ "code": "OK", "data": { "sn": "FR-20260917-001", "existed": false } }
```

| code | 說明 |
|---|---|
| `FREE_ROUND_CAP` | 當月名目總額（次數 × 注額）超過上限 |
| `BET_AMOUNT_RANGE` | 注額超出上下限 |
| `ACC_NOT_FOUND` | 玩家不存在 |
| `GAME_NOT_FOUND` | 遊戲代碼無效 |
| `WRONG_OPERATION` | 參數無法發放（次數、注額、帳號） |
</Card>

## POST `/free_round/cancel`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `sn` | 是 | string | 活動單號 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
`data` 為 `null`。剩餘次數歸零。已消耗次數仍保留於注單歷史。

```json
{ "code": "OK", "data": null }
```

無此活動：`ACC_NOT_FOUND`。
</Card>

## POST `/free_round/list`

<Card title="請求" icon="arrow-up-from-bracket">
| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `page` | 是 | integer | ≥ 1 |
| `perpage` | 是 | integer | 1–100 |
| `acc` | 否 | string | 篩選玩家 |
| `start_at` / `end_at` | 否 | integer | Unix 秒 |
</Card>

<Card title="回應" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `row_count` | integer | 總筆數 |
| `page_count` | integer | 總頁數 |
| `list` | array | 活動列 |

`list[]`：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `sn` | string | 活動單號 |
| `game_code` | string | 遊戲代碼 |
| `bet_amount` | number | 名目注額 |
| `total` | integer | 發放次數 |
| `remain` | integer | 剩餘次數 |
| `expire_at` | integer | 到期 Unix 秒 |
| `created_at` | integer | 建立時間，Unix 秒 |
</Card>
