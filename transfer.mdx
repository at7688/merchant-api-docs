---
title: 轉帳
description: 轉帳錢包入金與出金。
---

適用於轉帳錢包。`sn` 為冪等鍵：同一業務事件對應唯一 `sn`，重複提交不會重複入帳。

| 欄位 | 約束 |
|---|---|
| `sn` | 英數與 `_` `-`，長度 6–120 |
| `acc` | 玩家帳號，不含前綴 |
| `amount` | 不得為 0。正數為入金（商戶 → 平台），負數為出金（平台 → 商戶） |
| 時間 | Unix 秒 |

## POST `/transfer/add`

```json
{ "sn": "T20260917-0001", "acc": "jordan", "amount": 100 }
```

出金例：`"amount": -50`。

```json
{ "code": "OK", "data": { "currency": "TWD", "balance": 100 } }
```

`balance` 為該筆完成後之平台餘額。

| code | 語意 | 處理 |
|---|---|---|
| `OK` | 入帳完成 | 不得重用該 `sn` |
| `TRANSFER_SN_EXIST` | 該 `sn` 已成功入帳 | 呼叫 `/transfer/check`。非失敗 |
| `BALANCE_INSUFFICIENT` | 出金餘額不足 | 未入帳 |
| `ACC_NOT_FOUND` | 玩家不存在 | 未入帳 |

HTTP 500 或連線中斷表示結果未決。須以**原 `sn`** 呼叫 `/transfer/check`：查得紀錄即已入帳；`TRANSFER_NOT_FOUND` 後方可使用新 `sn`。於 500 後立即更換 `sn` 重送可導致重複入帳。

## POST `/transfer/check`

```json
{ "sn": "T20260917-0001", "acc": "jordan" }
```

無紀錄時 `code` 為 `TRANSFER_NOT_FOUND`。成功時 `data` 含 `sn`、`amount`、`balance`、`created_at`。

## POST `/transfer/list`

速率限制：每商戶每分鐘 10 次。

| 欄位 | 必填 | 約束 |
|---|---|---|
| `page` | 是 | ≥ 1 |
| `perpage` | 是 | 1–100 |
| `start_at` | 是 | Unix 秒 |
| `end_at` | 是 | 須大於 `start_at` |
| `acc` | 否 | 篩選玩家 |

回應 `data`：`list`、`row_count`、`page_count`。
