---
title: 转账
description: 转账钱包上分与下分。
---

适用于转账钱包。`sn` 为幂等键。成功报文见 [传输协议](/zh-CN/protocol)。`agent`／`member` 见页末。

## POST `/transfer/add`

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `sn` | 是 | string | 商户订单号，6–120 |
| `acc` | 是 | string | 玩家账号，不含前缀 |
| `amount` | 是 | number | 不为 0。正数上分，负数下分 |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `currency` | string | [币种](/zh-CN/enums#currency) |
| `balance` | number | 本笔完成后的平台余额 |

| code | 说明 |
|---|---|
| `TRANSFER_SN_EXIST` | 该 `sn` 已入账；调用 `/transfer/check` |
| `BALANCE_INSUFFICIENT` | 下分余额不足 |
| `ACC_NOT_FOUND` | 玩家不存在 |

HTTP 500：以原 `sn` 调用 `/transfer/check`。
</Card>

## POST `/transfer/check`

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `sn` | 是 | string | |
| `acc` | 是 | string | |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `sn` | string | 转账单号 |
| `amount` | number | 金额 |
| `balance` | number | 该笔完成当时的平台余额 |
| `created_at` | integer | Unix 秒 |
| `agent` | object | 商户摘要 |
| `member` | object | 玩家摘要 |

无记录：`TRANSFER_NOT_FOUND`。
</Card>

## POST `/transfer/list`

限流：每商户每分钟 10 次。

<Card title="响应" icon="arrow-down-to-bracket">
`row_count`、`page_count`（integer），`list[]`：`sn`、`amount`、`balance`、`created_at`、`agent`、`member`。
</Card>

## 对象 `agent`／`member`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | integer | 内部标识 |
| `acc` | string | 完整账号 |
| `name` | string | 显示名称 |
| `player_type` | string | [账号类型](/zh-CN/enums#player-type) |
| `currency` | string | [币种](/zh-CN/enums#currency) |
| `sub_role` | string | [子角色](/zh-CN/enums#sub-role) |
