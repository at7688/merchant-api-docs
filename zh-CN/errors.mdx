---
title: 错误码表
description: 成功值仅为 OK。
---

`code` 等于 `OK` 表示成功，其余值表示失败。`data` 于多数错误为 `null`。

`ACC_NOT_ACTIVE`、`ACC_SUSPEND` 两张表皆有，以 `data` 区分：商户层带 `agent` 对象，玩家层为 `null`（仅 `/player/login`）。

## 传输与鉴权

| code | 定义 | 后续 |
|---|---|---|
| `AGENT_NOT_FOUND` | 外层 `agent_acc` 无法对应代理 | |
| `IP_NOT_ALLOWED` | 来源 IP 不在白名单，见 [G6](/zh-CN/protocol#g6) | |
| `API_KEY_INVALID` | ApiKey 未设定或长度非 32 字节 | |
| `DATA_FORMAT_INVALID` | `data` 非合法 hex | |
| `DECRYPT_FAILED` | 解密失败 | |
| `PARAM_INVALID` | 请求不合格：外层或内层 JSON 无法解析、字段类型不对、或字段验证未通过 | |
| `IP_BLOCKED` | 来源 IP 或国家被封锁 | |
| `ACC_NOT_ACTIVE` | 商户未启用。`data` 带 `{agent, status}` | 终止调用 |
| `ACC_SUSPEND` | 商户已暂停。`data` 带 `{agent, current_status}` | 终止调用 |
| `TOO_MANY_REQUESTS` | 超过速率，上限见 [G4](/zh-CN/protocol#g4) | |
| `INTERNAL_SERVER_ERROR` | 系统错误，伴随 HTTP 500。可能发生在业务逻辑执行中 | 见 [G3](/zh-CN/protocol#g3) |

除 `INTERNAL_SERVER_ERROR` 外，上述错误在请求进入业务逻辑前发生，重试得使用原参数。

## 业务

| code | 定义 | 后续 |
|---|---|---|
| `ACC_EXIST` | 玩家账号已存在。视为已建立 | |
| `ACC_NOT_FOUND` | 玩家不存在 | 调用 `/player/add` |
| `ACC_NOT_ACTIVE` | 玩家未启用。`data` 为 `null` | 拒绝进入游戏 |
| `ACC_SUSPEND` | 玩家已暂停。`data` 为 `null` | 拒绝进入游戏 |
| `BALANCE_INSUFFICIENT` | 余额不足 | 单一钱包 `bet`：以此 `code` 响应平台 |
| `TRANSFER_SN_EXIST` | `sn` 已成功入账。非失败 | 调用 `/transfer/check` |
| `TRANSFER_NOT_FOUND` | 无此转账 | 见 [G3](/zh-CN/protocol#g3) |
| `GAME_NOT_FOUND` | 游戏代码无效 | 以 `/game/list` 核对 |
| `BET_NOT_FOUND` | `/bet_rec/query` 该列查无此单。外层 `code` 仍为 `OK`。`TOUR_`／`SC_` 开头者不在注单内，见 [回调](/zh-CN/callback) | 见 [G3](/zh-CN/protocol#g3) |
| `GAME_MAINTAIN` | 游戏或类别维护中 | |
| `BET_AMOUNT_RANGE` | 注额超出该玩家该游戏上下限 | |
| `FREE_ROUND_CAP` | 超过商户当月赠送名义总额 | 不得重送同一批 |
| `WRONG_OPERATION` | 参数无法发放赠送旋转 | |
