查询接口不变更余额。`end_at` 须大于 `start_at`。成功报文见 [传输协议](/zh-CN/protocol)。`agent`／`member` 同 [转账](/zh-CN/transfer)。

时间字段并非每支都用下注时间：

| 接口 | `start_at`／`end_at` 对应 |
|---|---|
| `/bet_rec/list` | `updated_at`（含结算）。只用下注时间会漏掉区间内才结算的单 |
| `/jp_rec/list` | `created_at` |
| `/bet_report/list` | `beted_date` 或 `settled_date`／分钟，值为 UTC+8（`Asia/Shanghai`）当日 00:00 的 Unix 秒 |
| `/scratch_card_rec/list` | `updated_at` |
| `/transfer/list` | `created_at` |
| `/free_round/list` | `created_at` |

下列接口每商户每分钟 10 次。`acc` 空表示不筛玩家。

## POST `/game/list`

仅返回 `is_active=true` 的游戏。维护中游戏仍出现在清单，登录时才返回 `GAME_MAINTAIN`。响应 `list[]`：`id`（integer）、`code`（登录 `game_code`）、`name`（object，键为 [语系](/zh-CN/enums#lang)）、[游戏类别](/zh-CN/enums#game-category)、`game_type_code`。

## POST `/bet_rec/list`

请求：`page`、`perpage` 1–1000、`start_at`、`end_at`，可选 `acc`。

响应 `row_count`、`page_count`、`list[]`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `sn` | string | 注单号 |
| `round_sn` | string | 局号 |
| `game_category_code` | string | [游戏类别](/zh-CN/enums#game-category) |
| `game_type_code` | string | 类型 |
| `game_code` | string | 游戏 |
| `acc` | string | 完整账号 |
| `player_acc` | string | 不含前缀 |
| `bet_amount` | number | 投注额 |
| `win_amount` | number | 派奖额 |
| `valid_amount` | number | 有效投注 |
| `result` | number | 派奖 − 投注 |
| `free_game_type` | string | [免费游戏](/zh-CN/enums#free-game-type) |
| `beted_at` | integer | 下注时间 |
| `settled_at` | integer | 结算时间；未结算可为 0 |
| `status` | string | [注单状态](/zh-CN/enums#bet-status) |
| `agent` / `member` | object | 摘要 |
| `slot_bet_detail` | object | 游戏端明细 |

赠送旋转产生的注单仍在本列表，`bet_amount` 为名义注额。本接口不另给「是否赠送」字段。

## POST `/bet_rec/detail`

请求：`sn`、`lang`（[语系](/zh-CN/enums#lang)）。响应 `data.url`：牌面结果页 URL。

## POST `/bet_rec/query`

请求：`sns`（1–100）。外层 `code` 仍为 `OK`。`list[]` 与请求等长；每一列都有 `code`。有单：`code` `OK` + `status`（[注单状态](/zh-CN/enums#bet-status)）。无单：`code` `BET_NOT_FOUND`，无 `status`。先看该列 `code`。列上 `BET_NOT_FOUND` 不得据此自动退款。

## POST `/bet_report/list`

请求：`report_unit`（[汇总周期](/zh-CN/enums#report-unit)）、`time_unit`（[时间轴](/zh-CN/enums#time-unit)）。

响应 `list[]`：`datetime`、`bet_count`、`bet_member_count`、`bet_amount`、`valid_amount`、`win_amount`、`result`。

## POST `/jp_rec/list`

`list[]`：`sn`、[游戏类别](/zh-CN/enums#game-category)、`game_type_code`、`game_code`、[JP 类型](/zh-CN/enums#jp-type)、`desk_id`、`acc`、`player_acc`、`bet_amount`、`amount`（JP 派奖）、`beted_at`、`settled_at`、`agent`、`member`、`slot_bet_detail`。

## POST `/jp_rec/detail`

响应 `data.url`（`is_jp=1`）。

## POST `/scratch_card_rec/list`

`list[]`：`sn`（`SC_{id}`）、`activity_name`、`card_code`、`card_name`、`prize_level`、`prize_amount`、`status`（[刮刮卡状态](/zh-CN/enums#scratch-status)）、`player_acc`、`member`（可为 null）、`claimed_at`、`scratched_at`。请求可选 `lang`（[语系](/zh-CN/enums#lang)）。

`summary`：`total_count`、`pending_count`、`claimed_count`、`scratched_count`、`total_prize`、`scratched_prize`（已派奖金）。
