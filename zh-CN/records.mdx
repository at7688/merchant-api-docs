查询接口不变更余额。时间为 Unix 秒。`end_at` 须大于 `start_at`，否则 `PARAM_INVALID`。

下列接口限流为每商户每分钟 10 次：`/bet_rec/list`、`/jp_rec/list`、`/bet_report/list`、`/scratch_card_rec/list`。超出为 `TOO_MANY_REQUESTS`。

`acc` 不含前缀；省略表示该商户全部玩家。

## POST `/game/list`

内层得为 `{}`。`data.list` 元素含 `code`（对应登录 `game_code`）、`name`、`game_category_code`、`game_type_code`、`id`。

## POST `/bet_rec/list`

| 字段 | 必填 | 约束 |
|---|---|---|
| `page` | 是 | ≥ 1 |
| `perpage` | 是 | 1–1000 |
| `start_at` / `end_at` | 是 | Unix 秒 |
| `acc` | 否 | |

响应 `data`：`list`、`row_count`、`page_count`。

## POST `/bet_rec/detail`

| 字段 | 必填 | 约束 |
|---|---|---|
| `sn` | 是 | 长度 ≤ 120 |
| `lang` | 是 | BCP 47 |

## POST `/bet_rec/query`

| 字段 | 必填 | 约束 |
|---|---|---|
| `sns` | 是 | 1–100 个单号 |

`data.list` 元素含 `sn`、`status`。`UNKNOWN` 表示平台无此单，不得据此自动退款。

## POST `/bet_report/list`

| 字段 | 必填 | 约束 |
|---|---|---|
| `page` / `perpage` | 是 | perpage 1–1000 |
| `start_at` / `end_at` | 是 | |
| `report_unit` | 是 | `min` \| `day` |
| `time_unit` | 是 | `bet` \| `settle` |
| `acc` | 否 | |

## POST `/jp_rec/list`

参数同 `/bet_rec/list`。

## POST `/jp_rec/detail`

参数同 `/bet_rec/detail`。

## POST `/scratch_card_rec/list`

| 字段 | 必填 | 约束 |
|---|---|---|
| `page` / `perpage` | 是 | perpage 1–1000 |
| `start_at` / `end_at` | 是 | |
| `status` | 否 | `PENDING` \| `CLAIMED` \| `SCRATCHED` |
| `acc` | 否 | |
| `lang` | 否 | BCP 47 |
