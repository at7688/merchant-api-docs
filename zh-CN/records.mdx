查询接口不变更余额。`end_at` 须大于 `start_at`。成功报文见 [传输协议](/zh-CN/protocol)。`agent`／`member` 同 [转账](/zh-CN/transfer)。

时间字段并非每支都用下注时间：

| 接口 | `start_at`／`end_at` 对应 |
|---|---|
| `/bet_rec/list` | `updated_at`（含结算）。只用下注时间会漏掉区间内才结算的单 |
| `/jp_rec/list` | `created_at` |
| `/bet_report/list` | `beted_date` 或 `settled_date`／分钟，值为 UTC+8 当日 00:00 的 Unix 秒 |
| `/scratch_card_rec/list` | `updated_at` |
| `/transfer/list` | `created_at` |
| `/free_round/list` | `created_at` |

下列接口每商户每分钟 10 次。`acc` 空表示不筛玩家。

## POST `/game/list`

仅返回 `is_active=true` 的游戏。维护中游戏仍出现在清单，登录时才返回 `GAME_MAINTAIN`。响应 `list[]`：`id`（integer）、`code`（登录 `game_code`）、`name`（object，语种为键）、`game_category_code`、`game_type_code`。

## POST `/bet_rec/list`

请求：`page`、`perpage` 1–1000、`start_at`、`end_at`，可选 `acc`。

响应 `row_count`、`page_count`、`list[]`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `sn` | string | 注单号 |
| `round_sn` | string | 局号 |
| `game_category_code` | string | 类别 |
| `game_type_code` | string | 类型 |
| `game_code` | string | 游戏 |
| `acc` | string | 完整账号 |
| `player_acc` | string | 不含前缀 |
| `bet_amount` | number | 投注额 |
| `win_amount` | number | 派奖额 |
| `valid_amount` | number | 有效投注 |
| `result` | number | 派奖 − 投注 |
| `free_game_type` | string | `NONE`、`TRIGGER`、`PURCHASE` |
| `beted_at` | integer | 下注时间 |
| `settled_at` | integer | 结算时间；未结算可为 0 |
| `status` | string | `PENDING`、`PROCESSING`、`FINISH`、`CANCEL` |
| `agent` / `member` | object | 摘要 |
| `slot_bet_detail` | object | 游戏端明细 |

## POST `/bet_rec/detail`

请求：`sn`、`lang`。响应 `data.url`：牌面结果页 URL。

## POST `/bet_rec/query`

请求：`sns`（1–100）。响应 `list[]`：`sn`、`status`（含 `UNKNOWN`）。`UNKNOWN` 不得据此自动退款。

## POST `/bet_report/list`

请求：`report_unit`（`min`\|`day`）、`time_unit`（`bet`\|`settle`）。

响应 `list[]`：`datetime`、`bet_count`、`bet_member_count`、`bet_amount`、`valid_amount`、`win_amount`、`result`。

## POST `/jp_rec/list`

`list[]`：`sn`、`game_category_code`、`game_type_code`、`game_code`、`jp_type`、`desk_id`、`acc`、`player_acc`、`bet_amount`、`amount`（JP 派奖）、`beted_at`、`settled_at`、`agent`、`member`、`slot_bet_detail`。

## POST `/jp_rec/detail`

响应 `data.url`（`is_jp=1`）。

## POST `/scratch_card_rec/list`

`list[]`：`sn`（`SC_{id}`）、`activity_name`、`card_code`、`card_name`、`prize_level`、`prize_amount`、`status`、`player_acc`、`member`（可为 null）、`claimed_at`、`scratched_at`。

`summary`：`total_count`、`pending_count`、`claimed_count`、`scratched_count`、`total_prize`、`scratched_prize`（已派奖金）。
