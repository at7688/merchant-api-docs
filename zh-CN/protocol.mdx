## 请求

| 项目 | 规定 |
|---|---|
| 方法 | `POST` |
| 标头 | `Content-Type: application/json` |
| 编码 | UTF-8 |
| URL | `{base}{path}` |

### 外层

```json
{ "agent_acc": "kiwi01", "data": "<ciphertext hex>" }
```

| 字段 | 必填 | 类型 | 约束 |
|---|---|---|---|
| `agent_acc` | 是 | string | 英数，长度 ≤ 60 |
| `data` | 是 | string | 内层明文加密后之十六进制 |

### 内层

UTF-8 JSON 对象，字段为 snake_case。该字节序列为 GCM 明文。

```json
{"acc":"jordan","name":"Amy"}
```

## AES-256-GCM

| 参数 | 值 |
|---|---|
| 算法 | AES-256-GCM |
| 密钥 | ApiKey 十六进制解码，32 字节 |
| nonce | 12 bytes，每个请求独立随机，禁止重用 |
| tag | 16 bytes |
| 密文排列 | `nonce ‖ ciphertext ‖ tag`，再编码为 hex |

单一钱包回调使用同一密钥与同一排列。

### 参考向量

仅供实现核对，不得作为正式密钥。明文为 `{"acc":"jordan","name":"Amy"}`（无空白、无换行）。

| | hex |
|---|---|
| key | `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f` |
| nonce | `000102030405060708090a0b` |
| data | `000102030405060708090a0b3c20b778a6c7f839e72ee5efd0875a41a1b8e6599559655e790a9ca760a850743566fe60e4ecf7193d174ad5dd` |

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");
function encrypt(plain, keyHex) {
  const key = Buffer.from(keyHex, "hex");
  const nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv("aes-256-gcm", key, nonce);
  const enc = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  return Buffer.concat([nonce, enc, cipher.getAuthTag()]).toString("hex");
}
```

```python Python
import os, binascii
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
def encrypt(plain: str, key_hex: str) -> str:
    key = binascii.unhexlify(key_hex)
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain.encode("utf-8"), None)
    return (nonce + ct).hex()
```

## 响应

各接口成功时均为该报文。`data` 字段见各接口页。

```json
{
  "api_version": "v1",
  "message": "",
  "code": "OK",
  "data": {},
  "trace_id": "3f2c1a0b-...."
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `api_version` | string | 当前为 `v1` |
| `message` | string | 附加说明，多为空字符串 |
| `code` | string | 业务结果。成功仅为 `OK` |
| `data` | object \| array \| null | 成功时的数据本体。错误时多为 `null` |
| `trace_id` | string | 本次请求标识 |

客户端须先解析 JSON，再读取 `code`。

## HTTP 状态

| 状态 | 语义 |
|---|---|
| 200 | 请求已处理。成功与否以 `code` 为准 |
| 404 | 路径不存在 |
| 500 | 结果未决。body 未必为 JSON |

代理不存在、来源 IP 未授权、解密失败、参数不合法等，响应 **HTTP 200** 且 `code` 为对应错误值。

HTTP 500：转账须以同一 `sn` 调用 `/transfer/check`；单一钱包须以商户账本及 `/bet_rec/query` 核对，不得径行冲正。
