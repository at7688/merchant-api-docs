---
title: 赠送旋转
description: 商户发放、取消、查询。活动单号幂等。超过月额度回 FREE_ROUND_CAP。
---

赠送旋转**不扣玩家余额**、不累积 JP。单钱包结算派彩仍可能打你的 `/player/win`。`bet_amount` 是名目注额，必须 **> 0**。

同一 `sn` 重送视为同一笔，成功 `data.existed` 为 true。

## POST `/free_round/add`

| 字段 | 必填 | 说明 |
|---|---|---|
| `sn` | 是 | 活动单号，最长 80 |
| `acc` | 是 | 玩家账号（不要前缀） |
| `game_code` | 是 | |
| `bet_amount` | 是 | > 0，须在该玩家该游戏单注上下限内 |
| `count` | 是 | 1–100 |
| `expire_at` | 是 | Unix 秒，0 表示用系统默认 |

成功：`{ "sn": "...", "existed": false }`。超额：`FREE_ROUND_CAP`。

## POST `/free_round/cancel`

`sn` 必填。剩余次数归零。

## POST `/free_round/list`

`page` ≥ 1，`perpage` 1–100。列表字段：`sn`、`game_code`、`bet_amount`、`total`、`remain`、`expire_at`、`created_at`。
