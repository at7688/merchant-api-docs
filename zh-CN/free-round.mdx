---
title: 免费旋转
description: 发放、取消、查询。
---

向指定玩家发放免费旋转。不扣除玩家余额、不计入 JP。单一钱包结算时仍可能发出 win 回调。报文见 [传输协议](/zh-CN/protocol)。

| 项目 | 规定 |
|---|---|
| `sn` | 全站唯一。已被使用则 `existed=true` 且不改本笔 |
| `game_code` | 转大写。空字符串表示不限游戏 |
| `expire_at` | `0`＝自此刻起 30 日；超过 30 日的时间戳截成 30 日 |
| 月额度 | 名义合计 `bet_amount × count`，日历月按 **UTC+8**（`Asia/Shanghai`）月初。后台未设上限则不检查 |
| 注额 | 若指定游戏，须落在该玩家该游戏 `bet_min`／`bet_max` |

消耗顺序：同一玩家多笔未用完记录按发放先后（`id` 升序）。玩家进入对应游戏并下注时，平台扣 1 次。转账钱包该转不扣平台余额、不计 JP。单一钱包该转不发 `/player/bet`，结算仍可能 `/player/win`。尚有剩余时购买免费旋转由平台拒绝。注单列表仍出现，名义注额；列表不另标是否赠送。剩余次数由平台持有，商户 API 无推送。

## POST `/free_round/add`

`sn` 为幂等键。

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `sn` | 是 | string | 活动单号，≤ 80 |
| `acc` | 是 | string | 玩家账号，不含前缀 |
| `game_code` | 是 | string | 游戏代码 |
| `bet_amount` | 是 | number | 名义注额，> 0 |
| `count` | 是 | integer | 次数，1–100 |
| `expire_at` | 是 | integer | 到期 Unix 秒；`0` 为系统默认 |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `sn` | string | 活动单号 |
| `existed` | boolean | `true` 表示该 `sn` 先前已发放 |

错误码：`FREE_ROUND_CAP`、`BET_AMOUNT_RANGE`、`ACC_NOT_FOUND`、`GAME_NOT_FOUND`。
</Card>

## POST `/free_round/cancel`

请求 `{ "sn": "..." }`。响应 `data` 为 `null`。剩余次数归零。

## POST `/free_round/list`

<Card title="响应" icon="arrow-down-to-bracket">
`row_count`、`page_count`，`list[]`：`sn`、`game_code`、`bet_amount`、`total`、`remain`、`expire_at`、`created_at`。
</Card>
