AT Gaming 商户 API 提供玩家账户、资金、游戏进入与账务查询。全部调用为 `HTTPS` `POST`，`Content-Type: application/json; charset=utf-8`。内层参数经 AES-256-GCM 加密后置于外层 `data`。规格见 [传输协议](/zh-CN/protocol)。

## 环境

| 环境 | Base URL |
|---|---|
| 测试 | `https://api.at-dev.app/api/v1` |
| 正式 | `https://api.at-gaming.app/api/v1` |

来源 IP 须列入该商户白名单，否则响应 `IP_NOT_ALLOWED`。

## 凭证

| 字段 | 说明 |
|---|---|
| `agent_acc` | 商户代理账号。置于请求外层，不加密 |
| ApiKey | 64 位十六进制字符（32 bytes），用于内层加解密 |

ApiKey 仅能出现在服务器端。缺陷报告须提供环境、路径、`agent_acc`、`trace_id` 与 UTC 时间，不得包含 ApiKey。

## 钱包模式

| 模式 | 余额所在 | 资金接口 |
|---|---|---|
| 转账钱包 | 平台 | 商户调用 [`/transfer/*`](/zh-CN/transfer) |
| 单钱包 | 商户 | 平台调用商户 [`/player/balance`](/zh-CN/seamless)、`/player/bet`、`/player/win`、`/player/bet_refund` |

两种模式共用玩家建立、登录与记录查询。加密与响应封套相同。

## 账号

内层 `acc` 为玩家账号（不含代理前缀）。平台存储为 `{agent_acc}_{acc}`。

| 方向 | 字段 | 例 |
|---|---|---|
| 商户 → 平台 | `acc` | `jordan` |
| 平台 → 商户（balance） | `acc` | `kiwi01_jordan` |
| 平台 → 商户（balance） | `player_acc` | `jordan` |
| 平台 → 商户（bet / win / refund） | `acc` | `jordan` |

重复附加前缀将导致 `ACC_NOT_FOUND`。

## 成功条件

仅当 JSON 字段 `code` 等于字符串 `OK` 时视为成功。不得以 HTTP 状态码或 `"200"` 判定成功。见 [错误码](/zh-CN/errors)。
