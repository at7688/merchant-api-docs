---
title: 回调
description: 平台对商户的回调。超时 15 秒。
---

适用于单一钱包。平台对商户 base URL 发出 `POST` `{ "data": "<hex>" }`。密钥与商户 ApiKey 相同。见 [传输协议](/zh-CN/protocol)。

<Warning>
成功时 `code` 为 `OK`。
</Warning>

超时 15 秒。以 `sn` 幂等。玩家掉线后仍可能收到 `/player/win`。

## POST `{base}/player/balance`

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `acc` | string | 含代理前缀 |
| `player_acc` | string | 不含前缀 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"` |
| `data.balance` | number | 商户侧当前余额 |
</Card>

## POST `{base}/player/bet`

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 幂等键 |
| `game_code` | string | 游戏代码 |
| `acc` | string | 不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 扣除额（正数） |
| `beted_at` | integer | 下注时间 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"`；余额不足为 `BALANCE_INSUFFICIENT` |
| `data.original_balance` | number | 扣款前余额 |
| `data.balance` | number | 扣款后余额 |
</Card>

## POST `{base}/player/win`

加款。锦标赛 `game_code` 为 `TOURNAMENT`。

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 幂等键 |
| `game_code` | string | 游戏或 `TOURNAMENT` |
| `acc` | string | 不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 增加额（正数） |
| `beted_at` / `settled_at` | integer | Unix 秒 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"` |
| `data.original_balance` | number | 加款前余额 |
| `data.balance` | number | 加款后余额 |
</Card>

## POST `{base}/player/refund`

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 对应 bet 单号 |
| `game_code` | string | 游戏代码 |
| `acc` | string | 不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 退回额（正数） |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"`。已退过仍回 `OK` |
| `data` | object \| omitted | 可省略 |
</Card>
