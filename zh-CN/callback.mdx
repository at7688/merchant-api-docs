---
title: 回调
description: 平台对商户的回调。超时 15 秒。
---

适用于单一钱包。平台对 `{MerchantApiUrl}{path}` 发出 `POST`，例如 `https://merchant.example/player/bet`。

```json
{ "data": "<AES-GCM hex>" }
```

| 项目 | 规定 |
|---|---|
| `MerchantApiUrl` | 与路径直接拼接，不得以 `/` 结尾 |
| 请求报文 | 仅 `data`，无 `agent_acc` |
| 加解密 | 与商户 API 同一 ApiKey、同一排列，见 [传输协议](/zh-CN/protocol) |
| `Content-Type` | `application/json` |
| 超时 | 15 秒，含连接与读取 |
| 商户响应 | JSON，顶层必有 `code`。成功为 `OK`。其余顶层字段忽略 |
| 商户 HTTP 状态 | 须为 2xx，否则平台视为结果未决 |

幂等见 [G1](/zh-CN/protocol#g1)，重发见 [G2](/zh-CN/protocol#g2)，结果未决见 [G3](/zh-CN/protocol#g3)。

## POST `{base}/player/balance`

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `acc` | string | 完整账号，含代理前缀 |
| `player_acc` | string | 不含前缀 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 成功为 `"OK"` |
| `data.balance` | number | 商户侧当前余额 |

```json
{ "code": "OK", "data": { "balance": 1680.4 } }
```
</Card>

## POST `{base}/player/bet`

扣款。

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 幂等键 |
| `game_code` | string | 游戏代码 |
| `acc` | string | 玩家账号，不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 扣除额（正数） |
| `beted_at` | integer | 下注时间，Unix 秒 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 成功 `"OK"`；余额不足 `BALANCE_INSUFFICIENT` |
| `data.original_balance` | number | 扣款前余额 |
| `data.balance` | number | 扣款后余额 |

```json
{
  "code": "OK",
  "data": { "original_balance": 1000, "balance": 900 }
}
```
</Card>

## POST `{base}/player/win`

加款。`game_code` 有三种来源：

| `game_code` | `sn` 形式 | 前置 `/player/bet` | 对账方式 |
|---|---|---|---|
| `/game/list` 的 `code` | 注单单号 | 有 | `/bet_rec/query` |
| [`TOURNAMENT`](/zh-CN/enums#game-code) | `TOUR_{赛事id}_{名次}_{会员id}` | 无 | 无查询接口，以商户账本为准 |
| [`SCRATCH_CARD`](/zh-CN/enums#game-code) | `SC_{票券id}` | 无 | [`/scratch_card_rec/list`](/zh-CN/records) |

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 幂等键 |
| `game_code` | string | 游戏代码、[`TOURNAMENT`](/zh-CN/enums#game-code) 或 [`SCRATCH_CARD`](/zh-CN/enums#game-code)，见上表 |
| `acc` | string | 不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 增加额，≥ 0（含未中奖） |
| `beted_at` | integer | 下注时间，Unix 秒 |
| `settled_at` | integer | 结算时间，Unix 秒 |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"` |
| `data.original_balance` | number | 加款前余额 |
| `data.balance` | number | 加款后余额 |

```json
{
  "code": "OK",
  "data": { "original_balance": 900, "balance": 1400 }
}
```
</Card>

## POST `{base}/player/refund`

退回同一 `sn` 的 `/player/bet` 实际扣下的金额。

<Card title="请求（解密后）" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 对应 bet 的单号 |
| `game_code` | string | 游戏代码 |
| `acc` | string | 不含前缀 |
| `name` | string | 显示名称 |
| `amount` | number | 退回额（正数） |
</Card>

<Card title="响应" icon="arrow-up-from-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | `"OK"`。已退过仍回 `OK`，余额不变 |
| `data` | object \| omitted | 可省略 |

```json
{ "code": "OK" }
```
</Card>

## 约束 {#constraints}

1. `TOURNAMENT`、`SCRATCH_CARD` 不在 `/game/list` 内，亦不在 `/bet_rec/query` 内。不得据此拒收。
2. `/player/refund`：商户未曾收到该 `sn` 的 bet，或曾以错误 `code` 拒绝者，回 `OK` 且不得加款。
3. 赠送旋转消耗时不发 `/player/bet`，结算仍可能发 `/player/win`（`amount` 可为 0）。见 [赠送旋转](/zh-CN/free-round)。
