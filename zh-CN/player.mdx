title: 玩家

---

`acc` **只送玩家账号**，不要加代理前缀。

## POST `/player/add`

已存在回 `ACC_EXIST`——可以当成功，接着去登录。

```json
{ "acc": "jordan", "name": "Amy" }
```

`acc` 英数 6–60；`name` 最长 30。成功：

```json
{ "code": "OK", "data": { "acc": "kiwi01_jordan", "player_acc": "jordan", "player_id": 123 } }
```

之后请求仍送 `jordan`。

## POST `/player/balance`

**只有转账钱包**。`{ "acc": "jordan" }`。成功 `data`：`currency`、`balance`。

## POST `/player/login`

请用玩家的**真实 IP**。

| 字段 | 必填 | 规则 |
|---|---|---|
| `acc` | 是 | 英数 6–60 |
| `lang` | 是 | BCP 47，如 `zh-CN` |
| `ip` | 是 | IPv4／IPv6 |
| `device` | 是 | `DESKTOP` 或 `MOBILE` |
| `game_code` | 否 | 空则进大厅 |
| `return_url` | 否 | 合法 URL |

成功 `data.url` 在玩家浏览器打开，不要改 query 里的 `token`。

## POST `/player/logout`

可省略 `acc`＝登出该商户下全部会员。请勿在排程里误送空值。
