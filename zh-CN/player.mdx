---
title: 玩家
description: 创建、余额、登录、登出。
---

内层 `acc` 不含代理前缀。时间为 Unix 秒。成功时外层报文见 [传输协议](/zh-CN/protocol)，下列仅列 `data`。

## POST `/player/add`

`ACC_EXIST` 表示账号已存在。

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `acc` | 是 | string | 玩家账号。英数 6–60，存储为小写 |
| `name` | 是 | string | 显示名称。长度 ≤ 30 |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `acc` | string | 平台完整账号 `{agent_acc}_{acc}` |
| `player_acc` | string | 不含前缀 |
| `player_id` | integer | 平台内部标识 |

```json
{
  "code": "OK",
  "data": { "acc": "kiwi01_jordan", "player_acc": "jordan", "player_id": 123 }
}
```
</Card>

## POST `/player/balance`

查询平台余额。适用于转账钱包。

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `acc` | 是 | string | 玩家账号 |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `currency` | string | 币种，例如 `TWD` |
| `balance` | number | 平台余额 |
</Card>

## POST `/player/login`

核发大厅或游戏 URL。`ip` 为玩家地址。

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `acc` | 是 | string | 玩家账号 |
| `lang` | 是 | string | BCP 47，例如 `zh-CN` |
| `ip` | 是 | string | 玩家 IPv4 或 IPv6 |
| `device` | 是 | string | `DESKTOP` 或 `MOBILE` |
| `game_code` | 否 | string | 省略则进入大厅 |
| `return_url` | 否 | string | 离开游戏后的返回 URL |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `url` | string | 大厅或游戏完整 URL，已含 `token`。客户端直接打开，不得修改 `token` |
</Card>

## POST `/player/logout`

<Card title="请求" icon="arrow-up-from-bracket">
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `acc` | 否 | string | 省略时登出该商户全部会员 |
</Card>

<Card title="响应" icon="arrow-down-to-bracket">
| 字段 | 类型 | 说明 |
|---|---|---|
| `count` | integer | 实际登出的会员数 |
</Card>
