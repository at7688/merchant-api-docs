## 請求

| 項目 | 規定 |
|---|---|
| 方法 | `POST` |
| 標頭 | `Content-Type: application/json` |
| 編碼 | UTF-8 |
| URL | `{base}{path}`，例如 `https://api.at-dev.app/api/v1/player/add` |
| 路徑前綴 | `/api/v1` |
| 額外標頭 | 不需要。來源 IP 取 `CF-Connecting-IP`，否則 `X-Forwarded-For`／連線位址，須在白名單 |

## 慣例

| 項目 | 規定 |
|---|---|
| `agent_acc` | 比對前轉小寫、去首尾空白 |
| `acc` | 去首尾空白後轉小寫，再與代理帳號組成 `{agent_acc}_{acc}` |
| `game_code` | 去空白後轉大寫。登入、贈送旋轉皆然 |
| 時間 | Unix **秒**（10 位）。帳務日界為 **UTC+8**（`Asia/Taipei`）當日 00:00 |
| 金額 | JSON number。小數最多兩位（資料庫 `DECIMAL`） |
| 選填篩選 | 空字串或 0 表示不套該條件 |
| 驗證失敗 | `code` 為 `PARAM_INVALID` |

回調 base URL 與路徑直接串接：`{MerchantApiUrl}/player/bet`。base **不得**以 `/` 結尾，否則會出現 `//player/bet`。

### 外層

```json
{
  "agent_acc": "kiwi01",
  "data": "<ciphertext hex>"
}
```

| 欄位 | 必填 | 型別 | 約束 |
|---|---|---|---|
| `agent_acc` | 是 | string | 英數，長度 ≤ 60，對應後台代理帳號 |
| `data` | 是 | string | 內層明文加密後之十六進位 |

### 內層

UTF-8 JSON 物件，欄位為 snake_case。該位元組序列為 GCM 明文。例：

```json
{"acc":"jordan","name":"Amy"}
```

## AES-256-GCM

| 參數 | 值 |
|---|---|
| 演算法 | AES-256-GCM |
| 金鑰 | ApiKey 十六進位解碼，長度 32 位元組 |
| nonce | 12 bytes，每個請求獨立隨機，禁止重用 |
| tag | 16 bytes |
| 密文排列 | `nonce ‖ ciphertext ‖ tag`，再編碼為 hex |

單錢包回調使用同一金鑰與同一排列。平台請求本文僅 `{ "data": "<hex>" }`，**不含** `agent_acc`。逾時 15 秒（含連線與讀取）。商戶回應須為 JSON，頂層含 `code`；`data` 欄位見 [回調](/callback)。HTTP 狀態須為 2xx，否則平台視為結果未決。

### 參考向量

僅供實作核對，不得作為正式金鑰。明文為 `{"acc":"jordan","name":"Amy"}`（無空白、無換行）。

| | hex |
|---|---|
| key | `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f` |
| nonce | `000102030405060708090a0b` |
| data | `000102030405060708090a0b3c20b778a6c7f839e72ee5efd0875a41a1b8e6599559655e790a9ca760a850743566fe60e4ecf7193d174ad5dd` |

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");

function encrypt(plain, keyHex) {
  const key = Buffer.from(keyHex, "hex");
  const nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv("aes-256-gcm", key, nonce);
  const enc = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  return Buffer.concat([nonce, enc, cipher.getAuthTag()]).toString("hex");
}
```

```python Python
import os, binascii
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

def encrypt(plain: str, key_hex: str) -> str:
    key = binascii.unhexlify(key_hex)
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain.encode("utf-8"), None)
    return (nonce + ct).hex()
```

## 回應

各接口成功時均為此信封。`data` 之欄位見該接口頁。

```json
{
  "api_version": "v1",
  "message": "",
  "code": "OK",
  "data": {},
  "trace_id": "3f2c1a0b-...."
}
```

| 欄位 | 型別 | 說明 |
|---|---|---|
| `api_version` | string | API 版本，目前為 `v1` |
| `message` | string | 附加說明，多數為空字串 |
| `code` | string | 業務結果。成功僅為 `OK` |
| `data` | object \| array \| null | 成功時之資料本體。錯誤時多為 `null` |
| `trace_id` | string | 本次請求識別，對帳與缺陷報告使用 |

成功與否以 `code` 為準。

路徑不存在為 HTTP 404。HTTP 500 表示結果未決，body 未必為 JSON：轉帳須以同一 `sn` 呼叫 `/transfer/check`；單錢包須以商戶帳本及 `/bet_rec/query` 核對，不得逕行沖正。
