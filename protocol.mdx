## 請求

| 項目 | 規定 |
|---|---|
| 方法 | `POST` |
| 標頭 | `Content-Type: application/json` |
| 編碼 | UTF-8 |
| URL | `{base}{path}`，例如 `https://api.at-dev.app/api/v1/player/add` |
| 路徑前綴 | `/api/v1` |
| 額外標頭 | 不需要。來源 IP 取 `CF-Connecting-IP`，否則 `X-Forwarded-For`／連線位址，須符合 [G6](#g6) |

## 慣例

| 項目 | 規定 |
|---|---|
| `agent_acc` | 比對前轉小寫、去首尾空白 |
| `acc` | 去首尾空白後轉小寫，再與代理帳號組成 `{agent_acc}_{acc}` |
| `game_code` | 去空白後轉大寫。登入、贈送旋轉皆然 |
| 時間 | Unix 秒（10 位）。帳務日界為 UTC+8（`Asia/Shanghai`）當日 00:00 |
| 金額 | JSON number。小數最多兩位（資料庫 `DECIMAL`） |
| 選填篩選 | 空字串或 0 表示不套該條件 |
| 請求不合格 | 外層或內層 JSON 無法解析、欄位型別不對、或欄位驗證未通過，一律 `PARAM_INVALID` |

### 外層

```json
{
  "agent_acc": "kiwi01",
  "data": "<ciphertext hex>"
}
```

| 欄位 | 必填 | 型別 | 約束 |
|---|---|---|---|
| `agent_acc` | 是 | string | 英數，長度 ≤ 60，對應後台代理帳號 |
| `data` | 是 | string | 內層明文加密後之十六進位 |

### 內層

UTF-8 JSON 物件，欄位為 snake_case。該位元組序列為 GCM 明文。例：

```json
{"acc":"jordan","name":"Amy"}
```

## AES-256-GCM

| 參數 | 值 |
|---|---|
| 演算法 | AES-256-GCM |
| 金鑰 | ApiKey 十六進位解碼，長度 32 位元組 |
| nonce | 12 bytes，每個請求獨立隨機，禁止重用 |
| tag | 16 bytes |
| 密文排列 | `nonce ‖ ciphertext ‖ tag`，再編碼為 hex |

單錢包回調使用同一金鑰與同一排列，封套見 [回調](/callback)。

### 參考向量 {#vectors}

明文為 `{"acc":"jordan","name":"Amy"}`（無空白、無換行）。

| | hex |
|---|---|
| key | `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f` |
| nonce | `000102030405060708090a0b` |
| data | `000102030405060708090a0b3c20b778a6c7f839e72ee5efd0875a41a1b8e6599559655e790a9ca760a850743566fe60e4ecf7193d174ad5dd` |

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");

function encrypt(plain, keyHex) {
  const key = Buffer.from(keyHex, "hex");
  const nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv("aes-256-gcm", key, nonce);
  const enc = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  return Buffer.concat([nonce, enc, cipher.getAuthTag()]).toString("hex");
}
```

```python Python
import os, binascii
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

def encrypt(plain: str, key_hex: str) -> str:
    key = binascii.unhexlify(key_hex)
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain.encode("utf-8"), None)
    return (nonce + ct).hex()
```
</CodeGroup>

## 回應

各接口成功時均為此信封。`data` 之欄位見該接口頁。

```json
{
  "api_version": "v1",
  "message": "",
  "code": "OK",
  "data": {},
  "trace_id": "3f2c1a0b-...."
}
```

| 欄位 | 型別 | 說明 |
|---|---|---|
| `api_version` | string | API 版本，目前為 `v1` |
| `message` | string | 附加說明，多數為空字串 |
| `code` | string | 業務結果。成功僅為 `OK` |
| `data` | object \| array \| null | 成功時之資料本體。錯誤時多為 `null`，少數錯誤帶診斷物件（見 [錯誤碼](/errors)） |
| `trace_id` | string | 本次請求識別，對帳與缺陷報告使用 |

成功與否以 `code` 為準。所有 `code`（含 `PARAM_INVALID`、`TOO_MANY_REQUESTS`）皆以 HTTP 200 回傳。

### HTTP 狀態

| 狀態 | 意義 |
|---|---|
| `200` | 請求已被處理。成功與否讀 `code` |
| `404` | 路徑不存在 |
| `500` | 結果未決，body 未必為 JSON。處置見 [G3](#g3) |

## 通則

以下六條跨多個接口。各接口頁以編號引用。

### G1 冪等鍵 {#g1}

| 項目 | 規定 |
|---|---|
| 鍵 | `sn`。`/transfer/add`、`/free_round/add` 與單錢包 `bet`／`win`／`refund` 皆以 `sn` 判定重複 |
| 首次收到 | 執行並持久化結果 |
| 重複且首次成功 | 回傳首次結果，餘額不變 |
| 重複且首次拒絕 | 回傳首次錯誤 `code` |
| 商戶端去重紀錄 | 至少保留 90 天 |

### G2 回調重送 {#g2}

逾時當下不重送同一封包。之後對同一 `sn` 可能再發：

| 情況 | 後續回調 |
|---|---|
| `/player/bet` 結果未決 | `/player/refund`（自動或值班補送） |
| `/player/win` 未成功（一般注單） | 再發 `/player/win`（遊戲重送或值班補送） |
| `/player/win` 未成功（錦標賽派彩） | 不自動重送，由值班補送。商戶以錯誤 `code` 拒絕者不補送 |
| 注單卡住逾時後取消 | `/player/refund` |

`/player/refund` 之自動重送：

| 項目 | 規定 |
|---|---|
| 首次間隔 | 60 秒 |
| 退避 | 60 × 2^n 秒，單次間隔上限 1 小時 |
| 總時限 | 24 小時 |
| 逾 24 小時 | 停止自動重送，轉「逾時待處理」，改由值班重送或人工結案，無時效上限 |

玩家離線後仍可能收到 `/player/win`。

### G3 結果未決 {#g3}

HTTP 500、連線中斷或逾時：不得假設成功或失敗，不得逕行沖正。

| 場景 | 規定 |
|---|---|
| `/transfer/add` | 以原 `sn` 呼叫 `/transfer/check`。查得紀錄即已入帳；回 `TRANSFER_NOT_FOUND` 後方可使用新 `sn` |
| 單錢包 | 以商戶帳本該 `sn` 為準，並以 `/bet_rec/query` 核對 |
| 其餘接口 | 重試得使用原參數 |

`/bet_rec/query` 列上 `BET_NOT_FOUND` 不得據以自動退款。轉帳不得更換 `sn`。

### G4 速率限制 {#g4}

| 接口 | 上限 |
|---|---|
| `/bet_rec/list`、`/jp_rec/list`、`/bet_report/list`、`/scratch_card_rec/list` | 每商戶每分鐘 10 次 |
| 其餘接口 | 不限流 |

超出為 `TOO_MANY_REQUESTS`。

### G5 資料保留期限 {#g5}

| 對象 | 期限 |
|---|---|
| 彙總資料（`/bet_report/list`） | 60 天。更早的區間回空清單（`code` 為 `OK`、`row_count` 為 0） |
| 注單（`/bet_rec/list`、`/bet_rec/query`） | 不受 60 天限制 |
| 商戶端 `sn` 去重紀錄 | 至少 90 天 |
| 贈送旋轉未指定 `expire_at` | 自發放起 30 日 |

### G6 金鑰與來源位址 {#g6}

| 項目 | 規定 |
|---|---|
| ApiKey | 僅能置於伺服器端 |
| 參考向量之金鑰 | 不得作為正式金鑰 |
| 來源 IP | 須列入該商戶白名單，否則回應 `IP_NOT_ALLOWED` |
| 白名單比對 | 逐筆 IP 位址完全比對，不支援網段／CIDR。每個出口位址個別登記，含 NAT 位址池全部位址 |
| IPv6 | 須與來源位址字面完全相同 |
| 缺陷報告 | 提供環境、路徑、`agent_acc`、`trace_id` 與 UTC 時間，不含 ApiKey |
