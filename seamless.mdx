---
title: 單錢包
description: 平台對商戶之回呼。Timeout 15 秒。
---

適用於單錢包。平台對商戶 base URL 發出 `POST`，本文為：

```json
{ "data": "<AES-GCM hex>" }
```

解密金鑰與商戶 API 之 ApiKey 相同。排列見 [傳輸協議](/protocol)。

<Warning>
成功條件：HTTP 200，且 JSON `code` 為字串 `"OK"`。`"200"`、數值 `200` 或其他字串均視為失敗。
</Warning>

## 接口

| 路徑 | 時機 | 語意 |
|---|---|---|
| `/player/balance` | 進入遊戲、重新整理 | 回傳餘額 |
| `/player/bet` | 下注 | 扣款 |
| `/player/win` | 結算 | 加款 |
| `/player/bet_refund` | 注單無法成立 | 退回對應 bet 金額 |

逾時為 **15 秒**。逾時後平台不立即重送同一封包；扣款結果未決時可能續發 `bet_refund`。商戶須在時限內完成 HTTP 回應。

玩家離線後仍可能收到 `/player/win`。不得以離線為由拒絕。

## 冪等

動錢請求皆含 `sn`。商戶須以 `sn` 為唯一鍵：

| 狀態 | 行為 |
|---|---|
| 未見該 `sn` | 執行扣／加並持久化結果，回應 `OK` |
| 已成功處理 | 回傳首次結果，餘額不變 |
| 已明確拒絕 | 回傳首次錯誤 `code` |

## POST `{base}/player/balance`

```json
{
  "timestamp": 1758723906,
  "acc": "kiwi01_jordan",
  "player_acc": "jordan"
}
```

| 欄位 | 說明 |
|---|---|
| `acc` | 含代理前綴 |
| `player_acc` | 不含前綴 |

```json
{ "code": "OK", "data": { "balance": 1680.4 } }
```

## POST `{base}/player/bet`

```json
{
  "timestamp": 1758723906,
  "sn": "SGP2504300009402",
  "game_code": "MLCQ",
  "acc": "jordan",
  "name": "Amy",
  "amount": 100,
  "beted_at": 1758723906
}
```

`acc` 不含前綴。`amount` 為扣除額（正數）。

```json
{
  "code": "OK",
  "data": { "original_balance": 1000, "balance": 900 }
}
```

餘額不足：HTTP 200，`code` 為 `BALANCE_INSUFFICIENT`。

## POST `{base}/player/win`

加款。錦標賽派彩之 `game_code` 為 `TOURNAMENT`。

| 欄位 | 說明 |
|---|---|
| `sn` | 冪等鍵 |
| `amount` | 增加額（正數） |
| `beted_at` / `settled_at` | Unix 秒 |

回應 `data`：`original_balance`（加款前）、`balance`（加款後）。

## POST `{base}/player/bet_refund`

欄位：`sn`、`game_code`、`acc`、`name`、`amount`、`timestamp`。退回對應下注。若該 `sn` 已退款，回應 `OK` 且餘額不變。
