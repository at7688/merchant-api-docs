---
title: 回調
description: 平台對商戶之回調。逾時 15 秒。
---

適用於單錢包。平台對 `{MerchantApiUrl}{path}` 發出 `POST`，例如 `https://merchant.example/player/bet`。

```json
{ "data": "<AES-GCM hex>" }
```

| 項目 | 規定 |
|---|---|
| `MerchantApiUrl` | 與路徑直接串接，不得以 `/` 結尾 |
| 請求本文 | 僅 `data`，無 `agent_acc` |
| 加解密 | 與商戶 API 同一 ApiKey、同一排列，見 [傳輸協議](/protocol) |
| `Content-Type` | `application/json` |
| 逾時 | 15 秒，含連線與讀取 |
| 商戶回應 | JSON，頂層必有 `code`。成功為 `OK`。其餘頂層欄位忽略 |
| 商戶 HTTP 狀態 | 須為 2xx。4xx 視為未處理（`/player/bet` 視同未扣款，不送 `/player/refund`）；5xx 與逾時視為結果未決 |

冪等見 [G1](/protocol#g1)，重送見 [G2](/protocol#g2)，結果未決見 [G3](/protocol#g3)。

## POST `{base}/player/bet`

扣款。

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 冪等鍵 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 玩家帳號，不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 扣除額（正數） |
| `beted_at` | integer | 下注時間，Unix 秒 |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | 成功 `"OK"`；餘額不足 `BALANCE_INSUFFICIENT` |
| `data.original_balance` | number | 扣款前餘額 |
| `data.balance` | number | 扣款後餘額 |

```json
{
  "code": "OK",
  "data": { "original_balance": 1000, "balance": 900 }
}
```
</Card>

## POST `{base}/player/win`

加款。`game_code` 有三種來源：

| `game_code` | `sn` 形式 | 前導 `/player/bet` | 對帳方式 |
|---|---|---|---|
| `/game/list` 之 `code` | 注單單號 | 有 | `/bet_rec/query` |
| [`TOURNAMENT`](/enums#game-code) | `TOUR_{賽事id}_{名次}_{會員id}` | 無 | 無查詢接口，以商戶帳本為準 |
| [`SCRATCH_CARD`](/enums#game-code) | `SC_{票券id}` | 無 | [`/scratch_card_rec/list`](/records) |

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 冪等鍵 |
| `game_code` | string | 遊戲代碼、[`TOURNAMENT`](/enums#game-code) 或 [`SCRATCH_CARD`](/enums#game-code)，見上表 |
| `acc` | string | 不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 增加額，≥ 0（含未中獎） |
| `beted_at` | integer | 下注時間，Unix 秒 |
| `settled_at` | integer | 結算時間，Unix 秒 |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | `"OK"` |
| `data.original_balance` | number | 加款前餘額 |
| `data.balance` | number | 加款後餘額 |

```json
{
  "code": "OK",
  "data": { "original_balance": 900, "balance": 1400 }
}
```
</Card>

## POST `{base}/player/refund`

退回同一 `sn` 之 `/player/bet` 實際扣下的金額。該 `sn` 可能未曾扣款，加款前先核對（見 [約束](#constraints) 2）。

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 對應 bet 之單號 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 退回額（正數） |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | `"OK"`。已退過仍回 `OK`，餘額不變 |
| `data` | object \| omitted | 得省略 |

```json
{ "code": "OK" }
```
</Card>

## 約束 {#constraints}

1. `TOURNAMENT`、`SCRATCH_CARD` 不在 `/game/list` 內，亦不在 `/bet_rec/query` 內。不得據此拒收。
2. `/player/refund`：先以 `sn` 核對是否確實扣過該筆 bet。扣過且未退過才退回 `amount`；未扣過（未收到該 bet，或曾以錯誤 `code` 拒絕）或已退過，回 `OK` 且不加款。
3. 贈送旋轉消耗時不發 `/player/bet`，結算仍可能發 `/player/win`（`amount` 可為 0）。見 [贈送旋轉](/free-round)。
