---
title: 回調
description: 平台對商戶之回調。Timeout 15 秒。
---

適用於單錢包。平台對 `{MerchantApiUrl}{path}` 發出 `POST`，例如 `https://merchant.example/player/bet`。`MerchantApiUrl` 不得以 `/` 結尾。

```json
{ "data": "<AES-GCM hex>" }
```

無 `agent_acc`。解密金鑰與商戶 API 之 ApiKey 相同。排列見 [傳輸協議](/protocol)。`Content-Type: application/json`。逾時 15 秒。

商戶回應須為 JSON，頂層必有 `code`。bet／win 之 `data.original_balance`、`data.balance` 為 number。其餘頂層欄位忽略。

<Warning>
成功時 `code` 為 `OK`。
</Warning>

逾時 **15 秒**。逾時當下不立即重送同一封包。之後仍可能對**同一 `sn`** 再發：

| 情況 | 後續回調 |
|---|---|
| `/player/bet` 結果未決 | `/player/refund`（自動或值班補送） |
| `/player/win` 未成功 | 稍後再發 `/player/win`（遊戲重送或值班補送） |
| 注單卡住逾時後取消 | `/player/refund` |

玩家離線後仍可能收到 `/player/win`。贈送旋轉消耗時**不發** `/player/bet`，結算仍可能發 `/player/win`（`amount` 可為 0）。

動錢請求以 `sn` 為唯一鍵：未見則執行並持久化；已成功則回傳首次結果且餘額不變；已拒絕則回傳首次錯誤 `code`。`bet`／`win`／`refund` 之 `acc` 為**不含前綴**；僅 `balance` 回調同時給完整 `acc` 與 `player_acc`。

## POST `{base}/player/balance`

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `acc` | string | 完整帳號，含代理前綴 |
| `player_acc` | string | 不含前綴 |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | 成功為 `"OK"` |
| `data.balance` | number | 商戶端目前餘額 |

```json
{ "code": "OK", "data": { "balance": 1680.4 } }
```
</Card>

## POST `{base}/player/bet`

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 冪等鍵 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 玩家帳號，不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 扣除額（正數） |
| `beted_at` | integer | 下注時間，Unix 秒 |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | 成功 `"OK"`；餘額不足例如 `BALANCE_INSUFFICIENT` |
| `data.original_balance` | number | 扣款前餘額 |
| `data.balance` | number | 扣款後餘額 |

```json
{
  "code": "OK",
  "data": { "original_balance": 1000, "balance": 900 }
}
```

餘額不足：`code` 為 `BALANCE_INSUFFICIENT`。
</Card>

## POST `{base}/player/win`

加款。錦標賽派彩之 `game_code` 見 [`TOURNAMENT`](/enums#game-code)。

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 冪等鍵 |
| `game_code` | string | 遊戲代碼，或 [錦標賽](/enums#game-code) |
| `acc` | string | 不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 增加額，≥ 0（含未中獎） |
| `beted_at` | integer | 下注時間 |
| `settled_at` | integer | 結算時間 |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | `"OK"` |
| `data.original_balance` | number | 加款前餘額 |
| `data.balance` | number | 加款後餘額 |
</Card>

## POST `{base}/player/refund`

<Card title="請求（解密後）" icon="arrow-down-to-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `timestamp` | integer | Unix 秒 |
| `sn` | string | 對應 bet 之單號 |
| `game_code` | string | 遊戲代碼 |
| `acc` | string | 不含前綴 |
| `name` | string | 顯示名稱 |
| `amount` | number | 退回額（正數） |
</Card>

<Card title="回應" icon="arrow-up-from-bracket">
| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | string | `"OK"`。已退過仍回 `OK`，餘額不變 |
| `data` | object \| omitted | 得省略 |
</Card>
