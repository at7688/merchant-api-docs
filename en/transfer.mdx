---
title: Transfers
description: Transfer-wallet credit and debit.
---

Transfer wallet only. `sn` is unique **per merchant**. Envelope: [Protocol](/en/protocol). `agent` / `member`: end of page. `start_at` / `end_at` on the list API filter `created_at`.

## POST `/transfer/add`

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `sn` | yes | string | Merchant reference, 6–120, alphanum plus `_` `-` |
| `acc` | yes | string | Player id, no prefix |
| `amount` | yes | number | ≠ 0. Positive = credit to platform; negative = debit |

```json
{ "sn": "T20260917-0001", "acc": "jordan", "amount": 100 }
```
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `currency` | string | [Currency](/en/enums#currency) |
| `balance` | number | Platform balance after this transfer |

| code | Description |
|---|---|
| `TRANSFER_SN_EXIST` | `sn` already posted; call `/transfer/check` |
| `BALANCE_INSUFFICIENT` | Debit exceeds balance |
| `ACC_NOT_FOUND` | Player missing |

HTTP 500: `/transfer/check` with the original `sn`.
</Card>

## POST `/transfer/check`

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `sn` | yes | string | |
| `acc` | yes | string | |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `sn` | string | Transfer id |
| `amount` | number | Amount |
| `balance` | number | Balance after this transfer |
| `created_at` | integer | Unix seconds |
| `agent` | object | Merchant profile |
| `member` | object | Player profile |

Missing: `TRANSFER_NOT_FOUND`.
</Card>

## POST `/transfer/list`

10 calls / merchant / minute.

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `page` | yes | integer | ≥ 1 |
| `perpage` | yes | integer | 1–100 |
| `start_at` / `end_at` | yes | integer | Unix seconds; `end_at` > `start_at` |
| `acc` | no | string | |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `row_count` | integer | Total rows |
| `page_count` | integer | Total pages |
| `list` | array | Newest first |

`list[]`: `sn`, `amount`, `balance`, `created_at`, `agent`, `member` — same meaning as `/transfer/check`.
</Card>
