---
title: Seamless
description: Platform callbacks. Timeout 15 seconds.
---

Seamless wallet only. The platform `POST`s to the merchant base URL:

```json
{ "data": "<AES-GCM hex>" }
```

The key matches the merchant ApiKey. Layout: [Protocol](/en/protocol).

<Warning>
Success: HTTP 200 and JSON `code` equal to the string `"OK"`. `"200"`, numeric `200`, and other strings are failures.
</Warning>

## Endpoints

| Path | When | Semantics |
|---|---|---|
| `/player/balance` | Game entry, refresh | Return balance |
| `/player/bet` | Bet | Debit |
| `/player/win` | Settlement | Credit |
| `/player/bet_refund` | Bet cannot complete | Refund that bet |

Timeout is **15 seconds**. The same packet is not resent immediately; an undetermined debit may be followed by `bet_refund`. The HTTP response must complete within the limit.

`/player/win` may arrive after disconnect. It must not be rejected on that basis.

## Idempotency

Money-moving calls include `sn` as a unique key.

| State | Behaviour |
|---|---|
| Unknown `sn` | Apply debit/credit, persist, return `OK` |
| Already succeeded | Return the first body; balance unchanged |
| Already rejected | Return the first error `code` |

## POST `{base}/player/balance`

```json
{
  "timestamp": 1758723906,
  "acc": "kiwi01_jordan",
  "player_acc": "jordan"
}
```

| Field | Description |
|---|---|
| `acc` | Prefixed |
| `player_acc` | Unprefixed |

```json
{ "code": "OK", "data": { "balance": 1680.4 } }
```

## POST `{base}/player/bet`

```json
{
  "timestamp": 1758723906,
  "sn": "SGP2504300009402",
  "game_code": "MLCQ",
  "acc": "jordan",
  "name": "Amy",
  "amount": 100,
  "beted_at": 1758723906
}
```

`acc` is unprefixed. `amount` is the debit (positive).

```json
{
  "code": "OK",
  "data": { "original_balance": 1000, "balance": 900 }
}
```

Insufficient funds: HTTP 200, `code` `BALANCE_INSUFFICIENT`.

## POST `{base}/player/win`

Credit. Tournament payouts use `game_code` `TOURNAMENT`. Fields include `beted_at` and `settled_at`. `data`: `original_balance` (before credit), `balance` (after).

## POST `{base}/player/bet_refund`

Fields: `sn`, `game_code`, `acc`, `name`, `amount`, `timestamp`. Refund the matching bet. If already refunded, return `OK` with unchanged balance.
