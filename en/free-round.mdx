---
title: Granted spins
description: Grant, cancel, list.
---

Issues free rounds on a given game. Rounds do not debit the player and do not accrue JP.

On seamless wallets, `/player/win` may still be invoked for wins (payout only). The merchant credits by `sn`.

`bet_amount` is the nominal stake. It must be > 0 and within that player’s min/max for the game (`BET_AMOUNT_RANGE`).

## POST `/free_round/add`

`sn` is idempotent. Repeats return `existed: true` without a second grant.

```json
{
  "sn": "FR-20260917-001",
  "acc": "jordan",
  "game_code": "MLCQ",
  "bet_amount": 10,
  "count": 5,
  "expire_at": 1759300000
}
```

| Field | Required | Constraints |
|---|---|---|
| `sn` | yes | ≤ 80 |
| `acc` | yes | no prefix |
| `game_code` | yes | valid game |
| `bet_amount` | yes | > 0 |
| `count` | yes | 1–100 |
| `expire_at` | yes | Unix seconds; `0` = default TTL |

```json
{ "code": "OK", "data": { "sn": "FR-20260917-001", "existed": false } }
```

| code | Definition |
|---|---|
| `FREE_ROUND_CAP` | Monthly nominal cap (count × stake) exceeded |
| `BET_AMOUNT_RANGE` | Stake outside min/max |
| `ACC_NOT_FOUND` | Player missing |
| `GAME_NOT_FOUND` | Invalid game |

Remaining rounds are decremented by the platform on each spin.

## POST `/free_round/cancel`

```json
{ "sn": "FR-20260917-001" }
```

Remaining rounds become zero. Consumed rounds remain in bet history. Unknown campaign: `ACC_NOT_FOUND`.

## POST `/free_round/list`

| Field | Required | Constraints |
|---|---|---|
| `page` | yes | ≥ 1 |
| `perpage` | yes | 1–100 |
| `acc` | no | |
| `start_at` / `end_at` | no | Unix seconds |

List fields: `sn`, `game_code`, `bet_amount`, `total`, `remain`, `expire_at`, `created_at`.
