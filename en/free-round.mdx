title: Granted spins
description: Grant, cancel, list.
---

Free rounds: no player debit, no JP. A win callback may still fire. Envelope: [Protocol](/en/protocol).

| Item | Rule |
|---|---|
| `sn` | Globally unique. If already used, `existed=true` and the row is unchanged |
| `game_code` | Uppercased. Empty = any game when consumed |
| `expire_at` | `0` = 30 days from now; later timestamps are capped at 30 days |
| Monthly cap | Nominal `bet_amount × count`, calendar month in **UTC+8**. Unset cap = unlimited |
| Stake | If a game is set, must lie within that player’s `bet_min` / `bet_max` |

Consumption order: oldest grant first (`id` ascending).

## POST `/free_round/add`

`sn` is idempotent.

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `sn` | yes | string | Campaign id, ≤ 80 |
| `acc` | yes | string | Player id, no prefix |
| `game_code` | yes | string | Game |
| `bet_amount` | yes | number | Nominal stake, > 0 |
| `count` | yes | integer | 1–100 |
| `expire_at` | yes | integer | Unix seconds; `0` = default TTL |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `sn` | string | Campaign id |
| `existed` | boolean | `true` if this `sn` was already granted |

Codes: `FREE_ROUND_CAP`, `BET_AMOUNT_RANGE`, `ACC_NOT_FOUND`, `GAME_NOT_FOUND`.
</Card>

## POST `/free_round/cancel`

Request: `{ "sn": "..." }`. Response `data` is `null`. Remaining rounds become 0.

## POST `/free_round/list`

<Card title="Request" icon="arrow-up-from-bracket">
`page` ≥ 1, `perpage` 1–100, optional `acc`, `start_at`, `end_at`.
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
`row_count`, `page_count`, `list[]`: `sn`, `game_code`, `bet_amount` (number), `total` / `remain` (integer), `expire_at`, `created_at` (Unix seconds).
</Card>
