## Request

| Item | Rule |
|---|---|
| Method | `POST` |
| Header | `Content-Type: application/json` |
| Encoding | UTF-8 |
| URL | `{base}{path}` |

### Outer body

```json
{
  "agent_acc": "kiwi01",
  "data": "<ciphertext hex>"
}
```

| Field | Required | Type | Constraints |
|---|---|---|---|
| `agent_acc` | yes | string | alphanum, ≤ 60 |
| `data` | yes | string | hex of the encrypted inner JSON |

### Inner body

UTF-8 JSON object, snake_case. Those bytes are the GCM plaintext.

```json
{"acc":"jordan","name":"Amy"}
```

## AES-256-GCM

| Parameter | Value |
|---|---|
| Algorithm | AES-256-GCM |
| Key | ApiKey decoded from hex, 32 bytes |
| nonce | 12 bytes, unique per request |
| tag | 16 bytes |
| Layout | `nonce ‖ ciphertext ‖ tag`, then hex |

Seamless-wallet callbacks use the same key and layout. The platform body is `{ "data": "<hex>" }`.

### Reference vector

Verification only — not a production key. Plaintext `{"acc":"jordan","name":"Amy"}` with no whitespace.

| | hex |
|---|---|
| key | `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f` |
| nonce | `000102030405060708090a0b` |
| data | `000102030405060708090a0b3c20b778a6c7f839e72ee5efd0875a41a1b8e6599559655e790a9ca760a850743566fe60e4ecf7193d174ad5dd` |

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");

function encrypt(plain, keyHex) {
  const key = Buffer.from(keyHex, "hex");
  const nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv("aes-256-gcm", key, nonce);
  const enc = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  return Buffer.concat([nonce, enc, cipher.getAuthTag()]).toString("hex");
}
```

```python Python
import os, binascii
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

def encrypt(plain: str, key_hex: str) -> str:
    key = binascii.unhexlify(key_hex)
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain.encode("utf-8"), None)
    return (nonce + ct).hex()
```

## Response

```json
{
  "api_version": "v1",
  "message": "",
  "code": "OK",
  "data": {},
  "trace_id": "3f2c1a0b-...."
}
```

| Field | Type | Description |
|---|---|---|
| `code` | string | Success value is only `OK` |
| `data` | object \| array \| null | Not a string |
| `trace_id` | string | Log correlation id |

Parse JSON, then read `code`. Do not abort solely on HTTP status without reading the body.

## HTTP status

| Status | Meaning |
|---|---|
| 200 | Processed. Outcome is `code` |
| 404 | Unknown path |
| 500 | Outcome undetermined. Body may not be JSON |

Unknown agent, unlisted IP, decrypt failure, and invalid parameters return **HTTP 200** with an error `code`.

HTTP 500: transfers use the same `sn` on `/transfer/check`. Seamless wallets reconcile against the merchant ledger and `/bet_rec/query`. Reversals must not be assumed.
