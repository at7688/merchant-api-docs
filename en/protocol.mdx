All merchant APIs:

- `POST`
- `Content-Type: application/json`
- UTF-8
- Path after the base, e.g. `https://api.at-dev.app/api/v1/player/add`

## Outer body (not encrypted)

```json
{
  "agent_acc": "kiwi01",
  "data": "<hex of encrypted inner JSON>"
}
```

| Field | Required | Rules |
|---|---|---|
| `agent_acc` | yes | alphanum, max 60 |
| `data` | yes | hex only |

We use `agent_acc` to pick the ApiKey.

## Inner JSON (encrypt this)

```json
{"acc":"jordan","name":"Amy"}
```

snake_case fields. Do not wrap in another `data`. UTF-8 bytes of this JSON are the plaintext.

## AES-256-GCM

| | |
|---|---|
| Algorithm | AES-256-GCM |
| ApiKey | 64 hex chars → 32 bytes |
| nonce | **12 bytes**, **new random value every request** |
| tag | 16 bytes |
| Wire format | `nonce ‖ ciphertext ‖ tag`, then hex |

Never reuse a nonce in production. The vector below uses a fixed nonce **only** so you can verify your code. **Do not use this key live.**

<CodeGroup>
```javascript Node.js
const crypto = require("crypto");

function encrypt(plain, keyHex) {
  const key = Buffer.from(keyHex, "hex");
  const nonce = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv("aes-256-gcm", key, nonce);
  const enc = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  const tag = cipher.getAuthTag();
  return Buffer.concat([nonce, enc, tag]).toString("hex");
}
```

```python Python
import os, binascii
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

def encrypt(plain: str, key_hex: str) -> str:
    key = binascii.unhexlify(key_hex)
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain.encode("utf-8"), None)
    return (nonce + ct).hex()
```
</CodeGroup>

Parse JSON **before** looking at `code`. Do not `throw` on `!response.ok` and stop — HTTP 200 can still be a business error; HTTP 500 may not even be JSON.

## Envelope we return

```json
{
  "api_version": "v1",
  "message": "",
  "code": "OK",
  "data": {},
  "trace_id": "3f2c1a0b-...."
}
```

`code` success value is only `OK`. `data` is an object or array, not a string. Always keep `trace_id` for support.

## HTTP status

| HTTP | What you do |
|---|---|
| 200 and `code=OK` | Success |
| 200 and `code≠OK` | Failed. See [errors](/en/errors) |
| 404 | Wrong path |
| 500 | **Unknown result**. Transfers: `/transfer/check`. Seamless: trust your ledger + `/bet_rec/query` |

Unknown agent, IP not allowed, decrypt/param errors: **HTTP 200** with a `code`.

## Seamless reverse direction

We POST `{ "data": "<hex>" }` to you. Decrypt with the same key. You respond with **plain** JSON; success `code` must be `"OK"`.
