---
title: Error codes
description: Success value is only OK.
---

`code` equal to `OK` denotes success. Any other value denotes failure. `data` is `null` on most errors.

`ACC_NOT_ACTIVE` and `ACC_SUSPEND` appear in both tables, distinguished by `data`: the merchant level carries an `agent` object, the player level is `null` (`/player/login` only).

## Transport and authentication

| code | Definition | Handling |
|---|---|---|
| `AGENT_NOT_FOUND` | Outer `agent_acc` does not match an agent | |
| `IP_NOT_ALLOWED` | Source IP not whitelisted, see [G6](/en/protocol#g6) | |
| `API_KEY_INVALID` | ApiKey missing or not 32 bytes | |
| `DATA_FORMAT_INVALID` | `data` is not valid hex | |
| `DECRYPT_FAILED` | Decrypt failed | |
| `PARAM_INVALID` | Malformed request: outer or inner JSON unparseable, wrong field type, or failed validation | |
| `IP_BLOCKED` | Source IP or country blocked | |
| `ACC_NOT_ACTIVE` | Merchant not active. `data` carries `{agent, status}` | Stop calling |
| `ACC_SUSPEND` | Merchant suspended. `data` carries `{agent, current_status}` | Stop calling |
| `TOO_MANY_REQUESTS` | Rate exceeded, limits in [G4](/en/protocol#g4) | |
| `INTERNAL_SERVER_ERROR` | System fault, with HTTP 500. May occur during business logic | See [G3](/en/protocol#g3) |

Except for `INTERNAL_SERVER_ERROR`, these errors occur before the request reaches business logic, and retries may reuse the original parameters.

## Business

| code | Definition | Handling |
|---|---|---|
| `ACC_EXIST` | Player account already exists. Treat as created | |
| `ACC_NOT_FOUND` | Player does not exist | Call `/player/add` |
| `ACC_NOT_ACTIVE` | Player not active. `data` is `null` | Deny game entry |
| `ACC_SUSPEND` | Player suspended. `data` is `null` | Deny game entry |
| `BALANCE_INSUFFICIENT` | Insufficient balance | Seamless `bet`: return this `code` to the platform |
| `TRANSFER_SN_EXIST` | `sn` already posted. Not a failure | Call `/transfer/check` |
| `TRANSFER_NOT_FOUND` | No such transfer | See [G3](/en/protocol#g3) |
| `GAME_NOT_FOUND` | Invalid game code | Check against `/game/list` |
| `BET_NOT_FOUND` | `/bet_rec/query`: no such bet for that item. The envelope `code` remains `OK`. An `sn` starting with `TOUR_` or `SC_` is not a bet, see [callbacks](/en/callback) | See [G3](/en/protocol#g3) |
| `GAME_MAINTAIN` | Game or category under maintenance | |
| `BET_AMOUNT_RANGE` | Stake outside the min/max for that player and that game | |
| `FREE_ROUND_CAP` | Merchant nominal grant total for the month exceeded | Do not resubmit the same batch |
| `WRONG_OPERATION` | Parameters cannot grant spins | |
