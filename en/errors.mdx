---
title: Error codes
description: Success is only OK.
---

Only **`OK`** is success. Other codes are failures, but **recovery differs**.

## Not processed yet

Fix and retry the **same** call. Do not mint a new transfer `sn`.

| code | Cause | What you do |
|---|---|---|
| `AGENT_NOT_FOUND` | Outer `agent_acc` mismatch | Match back office, lowercase |
| `IP_NOT_ALLOWED` | Egress IP not whitelisted | Send the real egress IP |
| `API_KEY_INVALID` | Missing or not 32 bytes | Ask ops to check the key |
| `DATA_FORMAT_INVALID` | `data` is not hex | Output hex |
| `DECRYPT_FAILED` | Key / nonce / tag / JSON | Use the protocol test vector |
| `PARAM_INVALID` | Inner validation | Required fields, lengths, Unix **seconds** |
| `IP_BLOCKED` | IP or country blocked | Contact ops; do not hammer |
| `ACC_NOT_ACTIVE` / `ACC_SUSPEND` | Merchant disabled | Contact ops |

## Business outcomes

| code | Cause | What you do |
|---|---|---|
| `ACC_EXIST` | Player already created | Treat as created; login |
| `ACC_NOT_FOUND` | No such player | `/player/add`; no extra prefix |
| `NAME_EXIST` | Duplicate name | Change `name` |
| `BALANCE_INSUFFICIENT` | Not enough balance | Credit first, or return this code on seamless bet |
| `TRANSFER_SN_EXIST` | This `sn` already succeeded | **Not a failure.** `/transfer/check` |
| `TRANSFER_NOT_FOUND` | No transfer | After HTTP 500, wait and check; then new `sn` if still missing |
| `GAME_NOT_FOUND` | Bad game code | `/game/list` |
| `GAME_MAINTAIN` | Maintenance | Retry later |
| `BET_AMOUNT_RANGE` | Stake outside min/max | Change stake |
| `FREE_ROUND_CAP` | Monthly grant cap | Do not retry the same batch |
| `TOO_MANY_REQUESTS` | 10 list calls / merchant / minute | Slow down |
| `INTERNAL_SERVER_ERROR` | Fault | Next section |

## HTTP 500 / unknown result

Do **not** assume success or failure.

1. Transfers: `/transfer/check` with the **same** `sn`. Found = posted; `TRANSFER_NOT_FOUND` = safe to use a new `sn`.
2. Seamless: your ledger for that `sn`; optional `/bet_rec/query`. `UNKNOWN` → **do not auto-refund**. Contact ops with the sn.
3. Include `trace_id`. Never send the ApiKey.

When you respond to us, success must be the string **`"OK"`**.
