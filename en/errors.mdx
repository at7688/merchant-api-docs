---
title: Error codes
description: Success value is only OK.
---

`code` `OK` denotes success. Any other value denotes failure. `data` is `null` on most errors.

## Transport and authentication

| code | Definition | Handling |
|---|---|---|
| `AGENT_NOT_FOUND` | Outer `agent_acc` does not match an agent | Verify the account |
| `IP_NOT_ALLOWED` | Source IP not whitelisted | Update the whitelist |
| `API_KEY_INVALID` | ApiKey missing or not 32 bytes | Verify the key |
| `DATA_FORMAT_INVALID` | `data` is not hex | Verify encoding |
| `DECRYPT_FAILED` | Decrypt failed | Verify key, nonce layout, JSON |
| `PARAM_INVALID` | Inner validation failed | Required fields, types, Unix seconds |
| `IP_BLOCKED` | IP or country blocked | Change source or request unblock |
| `ACC_NOT_ACTIVE` | Merchant inactive | Stop |
| `ACC_SUSPEND` | Merchant suspended | Stop |
| `TOO_MANY_REQUESTS` | List rate exceeded (10 / merchant / minute) | Reduce frequency |
| `INTERNAL_SERVER_ERROR` | Fault (with HTTP 500) | Outcome undetermined |

Retry may reuse the original parameters. Transfer `sn` must not be replaced for these codes.

## Business

| code | Definition | Handling |
|---|---|---|
| `ACC_EXIST` | Player already exists | Treat as created |
| `ACC_NOT_FOUND` | Player does not exist | `/player/add`; no extra prefix |
| `ACC_NOT_ACTIVE` | Player inactive | Deny game entry |
| `ACC_SUSPEND` | Player suspended | Deny game entry |
| `NAME_EXIST` | Duplicate name | Change `name` |
| `BALANCE_INSUFFICIENT` | Insufficient balance | Transfer: credit first. Seamless bet: return this code |
| `TRANSFER_SN_EXIST` | `sn` already posted | `/transfer/check`. Not a failure |
| `TRANSFER_NOT_FOUND` | No transfer | After HTTP 500, requery; then a new `sn` is allowed |
| `GAME_NOT_FOUND` | Invalid game code | `/game/list` |
| `GAME_MAINTAIN` | Maintenance | Defer entry |
| `BET_AMOUNT_RANGE` | Stake outside min/max | Adjust amount |
| `FREE_ROUND_CAP` | Monthly grant cap exceeded | Do not resubmit the batch |

## Undetermined outcome

HTTP 500 or a dropped connection does not imply success or failure.

| Context | Rule |
|---|---|
| `/transfer/add` | `/transfer/check` with the original `sn`. A row means posted; `TRANSFER_NOT_FOUND` allows a new `sn` |
| Seamless | Merchant ledger for that `sn`. `/bet_rec/query` `UNKNOWN` must not trigger an automatic refund |

Seamless-wallet callback success: `code` is `OK`.
