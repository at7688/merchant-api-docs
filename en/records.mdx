description: Bets, JP, reports, scratch cards.

Query APIs do not mutate balance. Times are Unix seconds. `end_at` must exceed `start_at` or the response is `PARAM_INVALID`.

Rate limit (10 / merchant / minute): `/bet_rec/list`, `/jp_rec/list`, `/bet_report/list`, `/scratch_card_rec/list`. Exceeding the limit returns `TOO_MANY_REQUESTS`.

`acc` excludes the prefix; omitted means all players under the merchant.

## POST `/game/list`

Inner body may be `{}`. `data.list` items:

| Field | Description |
|---|---|
| `code` | Game code (`game_code` on login) |
| `name` | Localised name |
| `game_category_code` | Category |
| `game_type_code` | Type |
| `id` | Internal id |

## POST `/bet_rec/list`

| Field | Required | Constraints |
|---|---|---|
| `page` | yes | ≥ 1 |
| `perpage` | yes | 1–1000 |
| `start_at` / `end_at` | yes | Unix seconds |
| `acc` | no | |

`data`: `list`, `row_count`, `page_count`.

## POST `/bet_rec/detail`

| Field | Required | Constraints |
|---|---|---|
| `sn` | yes | ≤ 120 |
| `lang` | yes | BCP 47 |

## POST `/bet_rec/query`

| Field | Required | Constraints |
|---|---|---|
| `sns` | yes | 1–100 identifiers |

Items: `sn`, `status`. `UNKNOWN` means no platform row. It must not trigger an automatic refund.
