Read-only. `end_at` > `start_at`. Envelope: [Protocol](/en/protocol). Profiles: [Transfers](/en/transfer).

Time columns are **not** always bet time:

| Endpoint | `start_at` / `end_at` |
|---|---|
| `/bet_rec/list` | `updated_at` (includes settlement). Filtering by bet time misses bets settled inside the window |
| `/jp_rec/list` | `created_at` |
| `/bet_report/list` | `beted_date` or `settled_date` / minute, Unix seconds at UTC+8 (`Asia/Shanghai`) 00:00 |
| `/scratch_card_rec/list` | `updated_at` |
| `/transfer/list` | `created_at` |
| `/free_round/list` | `created_at` |

Rate 10 / merchant / minute: `/bet_rec/list`, `/jp_rec/list`, `/bet_report/list`, `/scratch_card_rec/list`. Empty `acc` means no player filter.

## POST `/game/list`

<Card title="Response" icon="arrow-down-to-bracket">
Active games only (`is_active=true`). Maintenance games still appear; login returns `GAME_MAINTAIN`. `data.list[]`: `id` (integer), `code` (string, login `game_code`), `name` (object, keys: [language](/en/enums#lang)), [game category](/en/enums#game-category), `game_type_code` (string).
</Card>

## POST `/bet_rec/list`

<Card title="Request" icon="arrow-up-from-bracket">
`page` ≥ 1, `perpage` 1–1000, `start_at`, `end_at`, optional `acc`.
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
`row_count`, `page_count`, `list`.

`list[]`:

| Field | Type | Description |
|---|---|---|
| `sn` | string | Bet id |
| `round_sn` | string | Round id |
| `game_category_code` | string | [Game category](/en/enums#game-category) |
| `game_type_code` | string | Type |
| `game_code` | string | Game |
| `acc` | string | Full account |
| `player_acc` | string | Unprefixed |
| `bet_amount` | number | Stake |
| `win_amount` | number | Payout |
| `valid_amount` | number | Valid stake |
| `result` | number | Payout − stake |
| `free_game_type` | string | [Free-game](/en/enums#free-game-type) |
| `beted_at` | integer | Bet time |
| `settled_at` | integer | Settlement time; 0 if unset |
| `status` | string | [Bet status](/en/enums#bet-status) |
| `agent` / `member` | object | Profiles |
| `slot_bet_detail` | object | Game-specific |
</Card>

Granted-spin rounds still appear; `bet_amount` is the nominal stake. This endpoint does not flag grants.

## POST `/bet_rec/detail`

Request: `sn`, `lang` ([language](/en/enums#lang)). Response `data.url`: result-page URL.

## POST `/bet_rec/query`

Request: `sns` (1–100). Response `list[]`: `sn`, `status` ([bet status](/en/enums#bet-status)). If the first six characters of `sn` are `YYMMDD` (UTC+8, `Asia/Shanghai`), they prune partitions. `UNKNOWN` must not trigger an automatic refund.

## POST `/bet_report/list`

Request: `page`, `perpage` 1–1000, `start_at`, `end_at`, `report_unit` ([aggregation period](/en/enums#report-unit)), `time_unit` ([time axis](/en/enums#time-unit)), optional `acc`.

Response `list[]`: `datetime` (string), `bet_count`, `bet_member_count` (integer), `bet_amount`, `valid_amount`, `win_amount`, `result` (number). Plus `row_count`, `page_count`.

## POST `/jp_rec/list`

Request as bet list. `list[]`: `sn`, [game category](/en/enums#game-category), `game_type_code`, `game_code`, [JP type](/en/enums#jp-type), `desk_id`, `acc`, `player_acc`, `bet_amount`, `amount` (JP payout), `beted_at`, `settled_at`, `agent`, `member`, `slot_bet_detail`.

## POST `/jp_rec/detail`

Response `data.url` (JP result page, `is_jp=1`).

## POST `/scratch_card_rec/list`

Request: `page`, `perpage`, `start_at`, `end_at`, optional `status` ([scratch-card status](/en/enums#scratch-status)), `acc`, `lang` ([language](/en/enums#lang)).

`list[]`: `sn` (`SC_{id}`), `activity_name`, `card_code`, `card_name`, `prize_level`, `prize_amount`, `status`, `player_acc`, `member` (object or null), `claimed_at`, `scratched_at`.

`summary`: `total_count`, `pending_count`, `claimed_count`, `scratched_count`, `total_prize`, `scratched_prize` (paid amount).
