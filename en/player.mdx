title: Players
description: Create, balance, login, logout.

Encrypt the inner JSON. Send `acc` **without** the agent prefix.

## POST `/player/add`

Already exists → `ACC_EXIST` (treat as created).

```json
{ "acc": "jordan", "name": "Amy" }
```

| Field | Required | Rules |
|---|---|---|
| `acc` | yes | alphanum 6–60, stored lowercase |
| `name` | yes | max 30 |

Success:

```json
{
  "code": "OK",
  "data": { "acc": "kiwi01_jordan", "player_acc": "jordan", "player_id": 123 }
}
```

Later calls still send `jordan`.

## POST `/player/balance`

**Transfer wallet only.**

```json
{ "acc": "jordan" }
```

Success `data`: `currency`, `balance`.

## POST `/player/login`

Use the **player’s** IP, not your server IP.

| Field | Required | Rules |
|---|---|---|
| `acc` | yes | alphanum 6–60 |
| `lang` | yes | BCP 47 (`zh-TW`, `en`, `vi`) |
| `ip` | yes | IPv4/IPv6 |
| `device` | yes | `DESKTOP` or `MOBILE` |
| `game_code` | no | omit → lobby |
| `return_url` | no | valid URL |

```json
{
  "acc": "jordan",
  "lang": "en",
  "ip": "203.0.113.10",
  "device": "MOBILE",
  "game_code": "MLCQ"
}
```

Success: `{ "code": "OK", "data": { "url": "https://...?token=..." } }`. Open `url` as-is.

## POST `/player/logout`

```json
{ "acc": "jordan" }
```

Omit `acc` to log out **all** members under the merchant — do not send empty from a cron by mistake.
