Inner `acc` excludes the agent prefix. Times are Unix seconds. Envelope: [Protocol](/en/protocol). Tables below describe `data`.

## POST `/player/add`

`ACC_EXIST` means the account already exists.

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `acc` | yes | string | Player id, alphanum 6–60, stored lowercase |
| `name` | yes | string | Display name, ≤ 30 |

```json
{ "acc": "jordan", "name": "Amy" }
```
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `acc` | string | Full account `{agent_acc}_{acc}` |
| `player_acc` | string | Unprefixed player id |
| `player_id` | integer | Internal id |

```json
{
  "code": "OK",
  "data": { "acc": "kiwi01_jordan", "player_acc": "jordan", "player_id": 123 }
}
```
</Card>

## POST `/player/balance`

Transfer wallet only.

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `acc` | yes | string | Player id |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `currency` | string | e.g. `TWD` |
| `balance` | number | Platform balance |
</Card>

## POST `/player/login`

`ip` is the player address.

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `acc` | yes | string | Player id |
| `lang` | yes | string | BCP 47 |
| `ip` | yes | string | Player IPv4/IPv6 |
| `device` | yes | string | `DESKTOP` or `MOBILE` |
| `game_code` | no | string | Omitted → lobby |
| `return_url` | no | string | Valid URL |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `url` | string | Lobby or game URL including `token`. Open as-is |
</Card>

## POST `/player/logout`

<Card title="Request" icon="arrow-up-from-bracket">
| Field | Required | Type | Description |
|---|---|---|---|
| `acc` | no | string | Omitted: all members under the merchant |
</Card>

<Card title="Response" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|

</Card>
