Inner `acc` excludes the agent prefix. Timestamps are Unix seconds.

## POST `/player/add`

| Field | Required | Type | Constraints |
|---|---|---|---|
| `acc` | yes | string | alphanum, 6–60, stored lowercase |
| `name` | yes | string | ≤ 30 |

```json
{ "acc": "jordan", "name": "Amy" }
```

```json
{
  "code": "OK",
  "data": {
    "acc": "kiwi01_jordan",
    "player_acc": "jordan",
    "player_id": 123
  }
}
```

Subsequent requests still send `jordan`. `ACC_EXIST` means the account already exists.

## POST `/player/balance`

Platform balance. Transfer wallet only.

| Field | Required | Type | Constraints |
|---|---|---|---|
| `acc` | yes | string | alphanum, 6–60 |

`data`: `currency`, `balance`.

## POST `/player/login`

Issues a lobby or game URL. `ip` is the player address.

| Field | Required | Type | Constraints |
|---|---|---|---|
| `acc` | yes | string | alphanum, 6–60 |
| `lang` | yes | string | BCP 47 |
| `ip` | yes | string | IPv4 or IPv6 |
| `device` | yes | string | `DESKTOP` \| `MOBILE` |
| `game_code` | no | string | omitted → lobby |
| `return_url` | no | string | valid URL |

```json
{
  "acc": "jordan",
  "lang": "en",
  "ip": "203.0.113.10",
  "device": "MOBILE",
  "game_code": "MLCQ"
}
```

```json
{ "code": "OK", "data": { "url": "https://example/?token=..." } }
```

The client opens `data.url` without altering `token`.

| code | Condition |
|---|---|
| `ACC_NOT_FOUND` | Player missing |
| `ACC_NOT_ACTIVE` | Inactive |
| `ACC_SUSPEND` | Suspended |
| `GAME_NOT_FOUND` | Invalid game |
| `GAME_MAINTAIN` | Maintenance |

## POST `/player/logout`

| Field | Required | Description |
|---|---|---|
| `acc` | no | Omitted: all members under the merchant |

```json
{ "acc": "jordan" }
```
