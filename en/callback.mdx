---
title: Callbacks
description: Platform callbacks. Timeout 15 seconds.
---

Seamless wallet only. Platform `POST`s to `{MerchantApiUrl}{path}` (e.g. `https://merchant.example/player/bet`). Base must not end with `/`. Body `{ "data": "<hex>" }` with no `agent_acc`. Same ApiKey. [Protocol](/en/protocol). Timeout 15 seconds. Response JSON must include top-level `code`. bet/win `data.original_balance` and `data.balance` are numbers.

<Warning>
Success: `code` is `OK`.
</Warning>

Timeout 15 seconds. The same packet is not retried immediately. The **same `sn`** may later receive another `/player/win` or `/player/refund` (settle retry, operator resend, stuck-bet refund). Granted-spin consumption does **not** send `/player/bet`; settle may still send `/player/win` (`amount` may be 0). `acc` on bet/win/refund is unprefixed; only the balance callback sends both prefixed `acc` and `player_acc`. Idempotency on `sn`. `/player/win` may arrive after disconnect.

## POST `{base}/player/bet`

<Card title="Request (after decrypt)" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `timestamp` | integer | Unix seconds |
| `sn` | string | Idempotency key |
| `game_code` | string | Game |
| `acc` | string | Unprefixed |
| `name` | string | Display name |
| `amount` | number | Debit (positive) |
| `beted_at` | integer | Bet time |
</Card>

<Card title="Response" icon="arrow-up-from-bracket">
| Field | Type | Description |
|---|---|---|
| `code` | string | `"OK"` or e.g. `BALANCE_INSUFFICIENT` |
| `data.original_balance` | number | Before debit |
| `data.balance` | number | After debit |
</Card>

## POST `{base}/player/win`

Credit. Tournaments: `game_code` `TOURNAMENT`.

<Card title="Request (after decrypt)" icon="arrow-down-to-bracket">
| Field | Type | Description |
|---|---|---|
| `timestamp` | integer | Unix seconds |
| `sn` | string | Idempotency key |
| `game_code` | string | Game or `TOURNAMENT` |
| `acc` | string | Unprefixed |
| `name` | string | Display name |
| `amount` | number | Credit, ≥ 0 (including no win) |
| `beted_at` / `settled_at` | integer | Unix seconds |
</Card>

<Card title="Response" icon="arrow-up-from-bracket">
| Field | Type | Description |
|---|---|---|
| `code` | string | `"OK"` |
| `data.original_balance` | number | Before credit |
| `data.balance` | number | After credit |
</Card>
