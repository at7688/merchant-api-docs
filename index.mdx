AT Gaming 商戶 API 提供玩家帳戶、資金、遊戲進入與帳務查詢。全部呼叫為 `HTTPS` `POST`，`Content-Type: application/json; charset=utf-8`。內層參數經 AES-256-GCM 加密後置於外層 `data`。規格見 [傳輸協議](/protocol)。

依錢包模式選擇對接路徑。兩種模式之加密與回應封套相同，資金介面不同。

## 環境

| 環境 | Base URL |
|---|---|
| 測試 | `https://api.at-dev.app/api/v1` |
| 正式 | `https://api.at-gaming.app/api/v1` |

來源 IP 須列入該商戶白名單，否則回應 `IP_NOT_ALLOWED`。

## 憑證

| 欄位 | 說明 |
|---|---|
| `agent_acc` | 商戶代理帳號。置於請求外層，不加密 |
| ApiKey | 64 位十六進位字元（32 位元組），用於內層加解密 |

ApiKey 僅能置於伺服器端。缺陷報告須提供環境、路徑、`agent_acc`、`trace_id` 與 UTC 時間，不得包含 ApiKey。

## 帳號

內層 `acc` 為玩家帳號（不含代理前綴）。平台儲存為 `{agent_acc}_{acc}`，例如 `kiwi01_jordan`。

| 方向 | 欄位 | 例 |
|---|---|---|
| 商戶 → 平台 | `acc` | `jordan` |
| 平台 → 商戶（回調 balance） | `acc` | `kiwi01_jordan` |
| 平台 → 商戶（回調 balance） | `player_acc` | `jordan` |
| 平台 → 商戶（bet / win / refund） | `acc` | `jordan` |

重複附加前綴將導致 `ACC_NOT_FOUND`。

## 成功條件

僅當 JSON 欄位 `code` 等於字串 `OK` 時視為成功。不得以 HTTP 狀態碼或字串 `"200"` 判定成功。見 [錯誤碼](/errors)。
