所有商戶請求都是 **HTTPS POST**、**JSON**、**UTF-8**。內層參數先 JSON，再用商戶 **ApiKey**（32-byte hex）做 **AES-256-GCM**，密文 hex 放在外層 `data`。

| | 網址 |
|---|---|
| 測試 | `https://api.at-dev.app/api/v1` |
| 正式 | `https://api.at-gaming.app/api/v1` |

請把伺服器出口 IP 加進商戶白名單。

## 兩種錢包

**轉帳錢包**：玩家餘額在平台。商戶呼叫 `/player/*`、`/transfer/*` 建帳、登入、上下分。

**單錢包**：玩家餘額在商戶。商戶仍呼叫同一套建帳／登入／查紀錄；**下注與派彩由平台呼叫你的網址**（`/player/balance`、`/player/bet`、`/player/win`、`/player/bet_refund`）。你的 base URL 填在後台「商戶 API 網址」。

## 判斷結果

- 成功：`code` 為 **`OK`**（不是 `"200"`）。
- 業務／鑑權錯誤：多數為 **HTTP 200** + 非 OK 的 `code`。
- **HTTP 500**＝結果不明。body **不一定是 JSON**。轉帳請再打 `/transfer/check`，不要把 500 當確定失敗。

詳見 [傳輸協議](/protocol)、[錯誤碼](/errors)。
